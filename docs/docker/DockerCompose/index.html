4. Docker Compose

Docker Compose 是一个用于定义和运行多容器 Docker 应用程序的工具。通过 Compose，您可以使用 YAML 文件来配置应用程序的服务。

安装 Docker Compose​

Docker Compose 的安装取决于你的操作系统和 Docker 的安装方式：

1. Windows 和 macOS​

如果你安装的是 Docker Desktop，那么 Docker Compose 已经内置其中了，无需额外安装。你可以在终端输入 docker-compose --version 验证。

2. Linux 环境​

在 Linux 上，Docker Compose 可能需要手动安装。目前主要有两种版本：

  • Compose V2 (插件版)：作为 Docker 命令的插件使用，命令为 docker compose（不带连字符）。
    • 安装方式：通常通过包管理器（如 apt-get install docker-compose-plugin）安装。
  • Compose V1 (独立版)：独立的二进制文件，命令为 docker-compose。
    • 安装方式：从 GitHub 下载二进制文件并移动到 /usr/local/bin/。

建议：现在官方推荐使用 V2 版本。

为什么使用 Docker Compose？​

在复杂的应用中，我们通常需要多个容器协作（例如：Node.js + MySQL + Redis）。手动通过 docker run 一个个启动容器非常繁琐，且难以维护容器间的依赖和网络。

Docker Compose 允许我们：

  • 一键启动：使用一个命令即可启动所有服务。
  • 配置即代码：将所有的容器参数定义在 docker-compose.yml 中。
  • 服务隔离：默认会为这组服务创建一个独立的网络。

docker-compose.yml 示例​

以下是一个典型的全栈应用配置示例：

version: '3.8'

services:
  # 后端服务
  web:
    build: .
    ports:
      - "3000:3000"
    depends_on:
      - db
    environment:
      DATABASE_URL: mysql://user:password@db:3306/mydb

  # 数据库服务
  db:
    image: mysql:8.0
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: root_password
      MYSQL_DATABASE: mydb
    volumes:
      - db_data:/var/lib/mysql

volumes:
  db_data:

常用命令​

  • docker-compose up：构建、创建并启动容器。
  • docker-compose up -d：后台启动所有容器。
  • docker-compose ps：列出当前运行的服务。
  • docker-compose stop：停止正在运行的服务，但不会删除容器。
  • docker-compose down：停止并移除容器、网络、镜像（可选）和数据卷。
  • docker-compose logs -f：查看服务实时日志。
