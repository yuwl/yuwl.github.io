# 1. Docker 基础入门

Docker 是一个开源的应用容器引擎，让开发者可以打包他们的应用以及依赖包到一个可移植的镜像中，然后发布到任何流行的 Linux 或 Windows 操作系统的机器上，也可以实现虚拟化。

## 什么是 Docker？

Docker 的核心思想是：**一次分发，到处运行**。

Docker 利用容器（Container）来打包应用。容器之间是互相隔离的，这种隔离性使得容器非常轻量。

## 为什么使用 Docker？

- **环境一致性**：开发、测试、生产环境保持一致。
- **资源利用率高**：相比虚拟机，容器更轻量。
- **快速部署与回滚**：通过镜像可以快速启动或回滚。

## 安装 Docker

Docker 支持在 Windows、macOS 和 Linux 上安装。

### 1. Linux 环境安装 (以 Ubuntu 为例)

在 Linux 上通常使用官方提供的脚本进行快速安装：

```bash
# 更新 apt 软件包索引
sudo apt-get update

# 安装必要的系统工具
sudo apt-get install \
    apt-transport-https \
    ca-certificates \
    curl \
    gnupg \
    lsb-release

# 下载并安装脚本
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 启动 Docker 服务
sudo systemctl start docker
# 设置开机自启
sudo systemctl enable docker
```

### 2. Windows 环境安装

1. **下载安装包**：访问 [Docker Desktop for Windows](https://docs.docker.com/desktop/install/windows-install/) 下载 `.exe` 安装程序。
2. **启用 WSL 2**：推荐在 Windows 10/11 上配合 WSL 2（Windows Subsystem for Linux 2）使用。
3. **运行安装程序**：按照向导操作，安装完成后重启电脑。
4. **验证安装**：在命令提示符或 PowerShell 中运行 `docker --version`。

### 3. macOS 环境安装

1. **选择版本**：访问 [Docker Desktop for Mac](https://docs.docker.com/desktop/install/mac-install/)。请根据芯片类型（Intel 或 Apple Silicon/M1/M2）选择对应的下载包。
2. **拖拽安装**：双击下载的 `.dmg` 文件，将 Docker 图标拖拽到 `Applications` 文件夹。
3. **完成配置**：在菜单栏找到 Docker 图标，等待其启动完成。
