# 3. Docker 常用命令

以下是 Docker 开发中经常会用到的基础命令。

## 镜像管理

- `docker images`：列出本地镜像。
- `docker pull <image_name>`：从仓库拉取镜像。
- `docker build -t <tag_name> .`：使用当前目录下的 Dockerfile 构建镜像。
- `docker rmi <image_id>`：删除本地镜像。

## 容器管理

- `docker ps`：列出正在运行的容器。
- `docker ps -a`：列出所有容器（包括已停止的）。
- `docker run -d --name <name> -p <host_port>:<container_port> <image_name>`：以后台模式运行容器。
- `docker stop <container_id>`：停止运行中的容器。
- `docker rm <container_id>`：删除容器。
- `docker logs -f <container_id>`：查看容器实时日志。

## 进入容器

- `docker exec -it <container_id> /bin/bash`：进入正在运行的容器。
