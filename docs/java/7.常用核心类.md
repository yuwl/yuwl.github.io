

# 7. 常用核心类

## 1. 字符串处理 (String) —— Java 中的“一等公民”

在 Java 中，`String` 是最特殊的引用类型。

### 1.1 核心特性：不可变性 (Immutability)
一旦创建了 String 对象，它的内容就不能被改变。
*   为什么重要？ 任何修改字符串的操作（如拼接、替换），实际上都会在内存中创建一个新的 String 对象。

```java
String s = "Hello";
s = s + " World"; 
// 过程：
// 1. 内存中有 "Hello"
// 2. 内存中有 " World"
// 3. 创建新对象 "Hello World" 并让 s 指向它
// 4. 原来的 "Hello" 变成了垃圾（如果没有其他引用指向它）
```

### 1.2 字符串比较：`==` vs `equals()` (必考题)
*   `==`: 比较的是内存地址（是不是同一个对象）。
*   `equals()`: 比较的是内容（长得是不是一样）。

> ⚠️ 铁律：比较字符串内容时，永远使用 `equals()`。

```java
String s1 = "Java";
String s2 = new String("Java");

System.out.println(s1 == s2);      // false (地址不同)
System.out.println(s1.equals(s2)); // true  (内容相同)
```

### 1.3 常用方法速查
| 方法 | 描述 | 示例 |
| :--- | :--- | :--- |
| `length()` | 获取长度 | `"abc".length()` // 3 |
| `substring(int begin, int end)` | 截取子串 | `"Hello".substring(0, 2)` // "He" (含头不含尾) |
| `indexOf(String str)` | 查找位置 | `"apple".indexOf("l")` // 3 |
| `replace(old, new)` | 替换 | `"aba".replace("a", "c")` // "cbc" |
| `split(String regex)` | 分割 | `"a,b,c".split(",")` // 得到数组 ["a","b","c"] |
| `trim()` | 去除首尾空格 | `" a ".trim()` // "a" |

### 1.4 高效拼接：StringBuilder
如果在循环中进行字符串拼接，严禁使用 `+` 号，这会造成内存浪费和极差的性能。

*   `StringBuilder`: 可变、效率高、线程不安全（单线程推荐）。
*   `StringBuffer`: 可变、效率略低、线程安全（多线程用，现在很少用）。

```java
// ❌ 错误做法：性能极差
String s = "";
for (int i = 0; i < 1000; i++) {
    s += i; // 每次循环都创建新对象
}

// ✅ 正确做法：高效
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i); // 始终在同一个对象上操作
}
String result = sb.toString();
```

## 2. 包装类 (Wrapper Classes)

Java 是面向对象的，但 `int`、`double` 等基本数据类型不是对象。为了让它们能像对象一样使用（例如放入集合 `List<Integer>` 中），Java 提供了包装类。

### 2.1 对应关系
| 基本类型 | 包装类 (引用类型) | 说明 |
| :--- | :--- | :--- |
| int | Integer | 最常用 |
| char | Character | 注意拼写变化 |
| byte | Byte | 首字母大写 |
| boolean | Boolean | 首字母大写 |
| ... | ... | ... |

### 2.2 自动装箱与拆箱 (Autoboxing & Unboxing)
Java 编译器会自动帮你转换。
```java
// 自动装箱：基本类型 -> 包装类
Integer num = 100; // 等同于 Integer.valueOf(100)

// 自动拆箱：包装类 -> 基本类型
int val = num;     // 等同于 num.intValue()
```

### 2.3 字符串与数字转换 (高频)
```java
// String -> int
String str = "123";
int n = Integer.parseInt(str); 

// int -> String
String s = String.valueOf(100);
```

### 2.4 ⚠️ 经典大坑：Integer 缓存池
Integer 对 -128 到 127 之间的数字做了缓存。

```java
Integer a = 127;
Integer b = 127;
System.out.println(a == b); // true (都在缓存池中，是同一个对象)

Integer c = 128;
Integer d = 128;
System.out.println(c == d); // false (超出缓存范围，创建了两个新对象)

// 结论：包装类比较大小，一定要用 equals()，别用 ==
System.out.println(c.equals(d)); // true
```

## 3. 日期与时间 (Date & Time)

历史包袱：Java 早期提供了 `java.util.Date` 和 `java.util.Calendar`，但它们设计得很糟糕（可变、线程不安全、月份从0开始等）。
现代标准：从 Java 8 开始，强烈推荐使用 `java.time` 包下的新 API。

### 3.1 核心类 (Java 8+)
| 类名 | 描述 | 示例 |
| :--- | :--- | :--- |
| LocalDate | 只有日期 (年-月-日) | 生日、入职日期 |
| LocalTime | 只有时间 (时-分-秒) | 开店时间 |
| LocalDateTime | 日期 + 时间 | 下单时间、日志时间 |
| DateTimeFormatter | 格式化工具 | 替代 SimpleDateFormat |

### 3.2 常用操作代码
```java
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

public class TimeTest {
    public static void main(String[] args) {
        // 1. 获取当前时间
        LocalDateTime now = LocalDateTime.now();
        System.out.println(now); // 2023-10-27T10:15:30.123

        // 2. 自定义创建时间
        LocalDateTime dt = LocalDateTime.of(2025, 12, 25, 18, 00);

        // 3. 日期的加减 (链式调用)
        // 计算 3 天后的时间
        LocalDateTime future = now.plusDays(3);
        // 计算 1 小时前的时间
        LocalDateTime past = now.minusHours(1);

        // 4. 格式化 (Date -> String)
        DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
        String str = now.format(formatter);
        System.out.println("格式化后: " + str);

        // 5. 解析 (String -> Date)
        String timeStr = "2023-01-01 12:00:00";
        LocalDateTime parsed = LocalDateTime.parse(timeStr, formatter);
    }
}
```

### 3.3 为什么放弃 `java.util.Date`?
1.  非线程安全：`SimpleDateFormat` 在多线程下会报错，必须加锁。Java 8 的 `DateTimeFormatter` 是线程安全的。
2.  设计混乱：`Date` 中的年份是从 1900 开始算的，月份是从 0 开始的（0 代表 1 月），非常反人类。
3.  可变性：你可以随意修改 `Date` 对象的时间，这在多线程环境下很危险。Java 8 的 `LocalDateTime` 是不可变的。
