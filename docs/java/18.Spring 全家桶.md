## Spring 框架概述

### 什么是 Spring？

Spring 是一个轻量级的 Java 开发框架，它为现代 Java 应用程序提供了全面的基础设施支持。Spring 的核心特性包括：

- **IoC（控制反转）**：将对象的创建和管理交给 Spring 容器
- **AOP（面向切面编程）**：将横切关注点与业务逻辑分离
- **声明式事务管理**：简化事务处理
- **集成支持**：与各种技术框架的无缝集成

### Spring 生态系统

```
Spring Framework
├── Spring Core（核心容器）
│   ├── Beans（Bean 容器）
│   ├── Core（工具类）
│   └── Context（应用上下文）
├── Spring AOP（面向切面编程）
├── Spring MVC（Web 框架）
├── Spring Data（数据访问）
├── Spring Security（安全框架）
└── Spring Boot（快速开发）
```

### 为什么选择 Spring？

1. **降低开发成本**：通过 IoC 和 AOP 减少代码量
2. **提高代码质量**：良好的架构设计和代码规范
3. **易于测试**：支持依赖注入，便于单元测试
4. **生态丰富**：拥有庞大的社区和丰富的扩展

## IOC（控制反转）

### 什么是 IoC？

IoC（Inversion of Control，控制反转）是 Spring 的核心思想，它将对象的创建、依赖关系的维护交给 Spring 容器来管理，而不是由对象自己管理。

**传统方式**：
```java
public class UserService {
    private UserDao userDao = new UserDao(); // 自己创建依赖对象
}
```

**IoC 方式**：
```java
public class UserService {
    private UserDao userDao; // 由容器注入
    
    @Autowired
    public void setUserDao(UserDao userDao) {
        this.userDao = userDao;
    }
}
```

### IoC 容器

Spring 提供了两种 IoC 容器：

#### 1. BeanFactory

BeanFactory 是 Spring 的基础容器，提供了基础的 IoC 功能：

```java
import org.springframework.beans.factory.BeanFactory;
import org.springframework.beans.factory.xml.XmlBeanFactory;
import org.springframework.core.io.ClassPathResource;

public class BeanFactoryExample {
    public static void main(String[] args) {
        // 加载配置文件
        BeanFactory factory = new XmlBeanFactory(
            new ClassPathResource("applicationContext.xml")
        );
        
        // 获取 Bean
        UserService userService = (UserService) factory.getBean("userService");
        userService.saveUser();
    }
}
```

#### 2. ApplicationContext

ApplicationContext 是 BeanFactory 的扩展，提供了更多企业级功能：

```java
import org.springframework.context.ApplicationContext;
import org.springframework.context.support.ClassPathXmlApplicationContext;

public class ApplicationContextExample {
    public static void main(String[] args) {
        // 加载配置文件
        ApplicationContext context = 
            new ClassPathXmlApplicationContext("applicationContext.xml");
        
        // 获取 Bean
        UserService userService = (UserService) context.getBean("userService");
        userService.saveUser();
    }
}
```

### 依赖注入的方式

#### 1. 构造函数注入（推荐）

```java
@Service
public class UserService {
    private final UserDao userDao;
    private final EmailService emailService;
    
    // 通过构造函数注入
    @Autowired
    public UserService(UserDao userDao, EmailService emailService) {
        this.userDao = userDao;
        this.emailService = emailService;
    }
}
```

**优点**：
- 保证依赖不可变
- 确保对象在使用前完全初始化
- 便于单元测试

#### 2. Setter 方法注入

```java
@Service
public class UserService {
    private UserDao userDao;
    
    @Autowired
    public void setUserDao(UserDao userDao) {
        this.userDao = userDao;
    }
}
```

**适用场景**：
- 依赖可选
- 需要频繁变更依赖

#### 3. 字段注入（不推荐）

```java
@Service
public class UserService {
    @Autowired
    private UserDao userDao;
}
```

**缺点**：
- 无法设置 final 字段
- 难以进行单元测试
- 可能导致 NPE

### Bean 的生命周期

```java
import org.springframework.beans.factory.DisposableBean;
import org.springframework.beans.factory.InitializingBean;
import org.springframework.beans.factory.annotation.Autowired;
import javax.annotation.PostConstruct;
import javax.annotation.PreDestroy;

@Service
public class LifecycleBean implements InitializingBean, DisposableBean {
    
    private UserDao userDao;
    
    @Autowired
    public LifecycleBean(UserDao userDao) {
        System.out.println("1. 构造函数执行");
        this.userDao = userDao;
    }
    
    @PostConstruct
    public void postConstruct() {
        System.out.println("2. @PostConstruct 方法执行");
    }
    
    @Override
    public void afterPropertiesSet() throws Exception {
        System.out.println("3. InitializingBean.afterPropertiesSet() 执行");
    }
    
    @PreDestroy
    public void preDestroy() {
        System.out.println("4. @PreDestroy 方法执行");
    }
    
    @Override
    public void destroy() throws Exception {
        System.out.println("5. DisposableBean.destroy() 执行");
    }
}
```

## AOP（面向切面编程）

### 什么是 AOP？

AOP（Aspect-Oriented Programming，面向切面编程）是一种编程范式，它通过将横切关注点从业务逻辑中分离出来，提高代码的模块化程度。

**横切关注点**：日志、事务、权限校验、性能监控等在多个模块中重复出现的功能。

### AOP 核心概念

```
┌─────────────────────────────────────────────┐
│           业务逻辑方法（目标对象）            │
├─────────────────────────────────────────────┤
│  @Before  ────────────────────────────────  │
│     ↓                                           │
│  ┌─────────────────────────────┐            │
│  │        核心业务逻辑           │            │
│  └─────────────────────────────┘            │
│     ↑                                           │
│  @AfterReturning / @AfterThrowing / @After   │
└─────────────────────────────────────────────┘
```

| 概念 | 说明 |
|------|------|
| **Aspect（切面）** | 横切关注点的模块化，类似于类 |
| **Join Point（连接点）** | 程序执行的特定位置，如方法调用 |
| **Pointcut（切点）** | 匹配连接点的表达式 |
| **Advice（通知）** | 在切点上执行的动作 |
| **Target（目标对象）** | 被通知的对象 |
| **Proxy（代理）** | AOP 创建的对象 |

### AOP 通知类型

```java
import org.aspectj.lang.annotation.*;
import org.aspectj.lang.JoinPoint;
import org.aspectj.lang.ProceedingJoinPoint;
import org.springframework.stereotype.Component;

@Aspect
@Component
public class LoggingAspect {
    
    // 1. 前置通知 - 在目标方法执行前执行
    @Before("execution(* com.example.service.*.*(..))")
    public void beforeAdvice(JoinPoint joinPoint) {
        String methodName = joinPoint.getSignature().getName();
        Object[] args = joinPoint.getArgs();
        System.out.println("前置通知：执行方法 " + methodName + 
                          "，参数：" + Arrays.toString(args));
    }
    
    // 2. 后置通知 - 在目标方法执行后执行（无论成功或失败）
    @After("execution(* com.example.service.*.*(..))")
    public void afterAdvice(JoinPoint joinPoint) {
        System.out.println("后置通知：方法 " + 
                          joinPoint.getSignature().getName() + " 执行完毕");
    }
    
    // 3. 返回通知 - 在目标方法成功返回后执行
    @AfterReturning(
        pointcut = "execution(* com.example.service.*.*(..))",
        returning = "result"
    )
    public void afterReturningAdvice(JoinPoint joinPoint, Object result) {
        System.out.println("返回通知：方法 " + 
                          joinPoint.getSignature().getName() + 
                          " 返回结果：" + result);
    }
    
    // 4. 异常通知 - 在目标方法抛出异常后执行
    @AfterThrowing(
        pointcut = "execution(* com.example.service.*.*(..))",
        throwing = "exception"
    )
    public void afterThrowingAdvice(JoinPoint joinPoint, Throwable exception) {
        System.out.println("异常通知：方法 " + 
                          joinPoint.getSignature().getName() + 
                          " 抛出异常：" + exception.getMessage());
    }
    
    // 5. 环绕通知 - 在目标方法执行前后都执行
    @Around("execution(* com.example.service.*.*(..))")
    public Object aroundAdvice(ProceedingJoinPoint joinPoint) throws Throwable {
        long startTime = System.currentTimeMillis();
        
        System.out.println("环绕通知：方法开始执行");
        
        Object result = joinPoint.proceed(); // 执行目标方法
        
        long endTime = System.currentTimeMillis();
        System.out.println("环绕通知：方法执行结束，耗时：" + 
                          (endTime - startTime) + "ms");
        
        return result;
    }
}
```

### 切点表达式

```java
@Aspect
@Component
public class PointcutExamples {
    
    // 1. 匹配所有 public 方法
    @Before("execution(public * *(..))")
    public void matchAllPublicMethods() {}
    
    // 2. 匹配指定包下所有方法
    @Before("execution(* com.example.service.*.*(..))")
    public void matchServiceMethods() {}
    
    // 3. 匹配指定类所有方法
    @Before("execution(* com.example.service.UserService.*(..))")
    public void matchUserServiceMethods() {}
    
    // 4. 匹配返回类型为 String 的方法
    @Before("execution(java.lang.String com.example..*.*(..))")
    public void matchStringReturnMethods() {}
    
    // 5. 匹配参数个数和类型的方法
    @Before("execution(* com.example..*.*(java.lang.String, int))")
    public void matchMethodsWithStringAndIntParams() {}
    
    // 6. 匹配任意参数的方法
    @Before("execution(* com.example..*.*(..))")
    public void matchMethodsWithAnyParams() {}
    
    // 7. 使用注解匹配
    @Before("@annotation(com.example.annotation.Loggable)")
    public void matchAnnotatedMethods() {}
    
    // 8. 组合切点
    @Before(
        "execution(* com.example.service.*.*(..)) && " +
        "execution(* save*(..))"
    )
    public void matchCombinedPointcut() {}
    
    // 9. 定义切点并重用
    @Pointcut("execution(* com.example.service.*.*(..))")
    public void serviceLayer() {}
    
    @Before("serviceLayer()")
    public void beforeServiceMethods() {}
    
    // 10. 匹配自定义注解的类
    @Before("@within(com.example.annotation.Loggable)")
    public void matchAnnotatedClassMethods() {}
}
```

### 自定义注解实现 AOP

```java
import java.lang.annotation.*;

// 1. 定义自定义注解
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Loggable {
    String value() default "";
}

// 2. 使用注解标记方法
@Service
public class UserService {
    
    @Loggable("用户保存")
    public void saveUser(User user) {
        System.out.println("保存用户：" + user.getName());
    }
    
    @Loggable("用户查询")
    public User getUserById(Long id) {
        System.out.println("查询用户ID：" + id);
        return new User("张三", 25);
    }
}

// 3. 创建切面处理注解
@Aspect
@Component
public class LoggableAspect {
    
    @Around("@annotation(loggable)")
    public Object logExecutionTime(ProceedingJoinPoint joinPoint, 
                                   Loggable loggable) throws Throwable {
        String operation = loggable.value();
        String methodName = joinPoint.getSignature().getName();
        
        System.out.println("【开始】" + operation + "，方法：" + methodName);
        
        long startTime = System.currentTimeMillis();
        Object result = joinPoint.proceed();
        long endTime = System.currentTimeMillis();
        
        System.out.println("【结束】" + operation + "，耗时：" + 
                          (endTime - startTime) + "ms");
        
        return result;
    }
}
```

### AOP 实战案例

#### 1. 性能监控

```java
@Aspect
@Component
public class PerformanceMonitorAspect {
    
    private static final Logger logger = 
        LoggerFactory.getLogger(PerformanceMonitorAspect.class);
    
    @Around("@annotation(com.example.annotation.MonitorPerformance)")
    public Object monitorPerformance(ProceedingJoinPoint joinPoint) throws Throwable {
        String className = joinPoint.getTarget().getClass().getSimpleName();
        String methodName = joinPoint.getSignature().getName();
        
        long startTime = System.currentTimeMillis();
        
        try {
            Object result = joinPoint.proceed();
            long executionTime = System.currentTimeMillis() - startTime;
            
            logger.info("类: {}, 方法: {}, 执行时间: {}ms", 
                       className, methodName, executionTime);
            
            // 警告阈值
            if (executionTime > 1000) {
                logger.warn("性能警告：{}.{}, 执行时间过长: {}ms", 
                           className, methodName, executionTime);
            }
            
            return result;
        } catch (Exception e) {
            long executionTime = System.currentTimeMillis() - startTime;
            logger.error("类: {}, 方法: {}, 执行异常, 耗时: {}ms, 异常: {}", 
                        className, methodName, executionTime, e.getMessage());
            throw e;
        }
    }
}
```

#### 2. 事务管理

```java
@Aspect
@Component
public class TransactionAspect {
    
    @Autowired
    private TransactionManager transactionManager;
    
    @Around("@annotation(com.example.annotation.Transactional)")
    public Object manageTransaction(ProceedingJoinPoint joinPoint) throws Throwable {
        TransactionStatus status = 
            transactionManager.getTransaction(new DefaultTransactionDefinition());
        
        try {
            Object result = joinPoint.proceed();
            transactionManager.commit(status);
            return result;
        } catch (Exception e) {
            transactionManager.rollback(status);
            throw e;
        }
    }
}
```

#### 3. 权限校验

```java
@Aspect
@Component
public class AuthorizationAspect {
    
    @Autowired
    private SecurityService securityService;
    
    @Before("@annotation(com.example.annotation.RequirePermission)")
    public void checkPermission(JoinPoint joinPoint) {
        RequirePermission annotation = joinPoint.getSignature()
            .getMethod()
            .getAnnotation(RequirePermission.class);
        
        String requiredPermission = annotation.value();
        
        if (!securityService.hasPermission(requiredPermission)) {
            throw new AccessDeniedException("权限不足: " + requiredPermission);
        }
    }
}
```

## Spring MVC

### 什么是 Spring MVC？

Spring MVC 是 Spring 框架提供的 Web 框架，基于 MVC（Model-View-Controller）设计模式，用于开发灵活、松耦合的 Web 应用程序。

### MVC 架构

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   Browser    │────▶│  Controller  │────▶│    Service   │
│              │     │              │     │              │
└──────────────┘     └──────────────┘     └──────────────┘
                           │                      │
                           ▼                      ▼
                     ┌──────────────┐      ┌──────────────┐
                     │    Model     │◀─────│     DAO      │
                     │              │      │              │
                     └──────────────┘      └──────────────┘
                           │
                           ▼
                     ┌──────────────┐
                     │     View     │
                     │              │
                     └──────────────┘
```

### Spring MVC 核心组件

| 组件 | 说明 |
|------|------|
| **DispatcherServlet** | 前端控制器，处理所有请求 |
| **HandlerMapping** | 处理器映射器，将请求映射到处理器 |
| **Controller** | 处理器，处理业务逻辑 |
| **ModelAndView** | 模型和视图对象 |
| **ViewResolver** | 视图解析器，解析视图名称 |
| **View** | 视图，负责渲染页面 |

```java
import org.springframework.stereotype.Service;
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicLong;

@Service
public class UserService {
    
    private final ConcurrentHashMap<Long, User> userMap = new ConcurrentHashMap<>();
    private final AtomicLong idGenerator = new AtomicLong(1);
    
    public List<User> findAll() {
        return new ArrayList<>(userMap.values());
    }
    
    public User findById(Long id) {
        return userMap.get(id);
    }
    
    public User save(User user) {
        if (user.getId() == null) {
            user.setId(idGenerator.getAndIncrement());
        }
        userMap.put(user.getId(), user);
        return user;
    }
    
    public void deleteById(Long id) {
        userMap.remove(id);
    }
}
```

```java
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestControllerAdvice
public class GlobalExceptionHandler {
    
    // 1. 处理自定义异常
    @ExceptionHandler(BusinessException.class)
    public ResponseEntity<Map<String, Object>> handleBusinessException(
            BusinessException ex) {
        
        Map<String, Object> response = new HashMap<>();
        response.put("code", ex.getCode());
        response.put("message", ex.getMessage());
        response.put("timestamp", System.currentTimeMillis());
        
        return ResponseEntity.status(HttpStatus.BAD_REQUEST).body(response);
    }
    
    // 2. 处理参数校验异常
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, Object>> handleValidationException(
            MethodArgumentNotValidException ex) {
        
        Map<String, Object> errors = new HashMap<>();
        ex.getBindingResult().getFieldErrors().forEach(error -> {
            errors.put(error.getField(), error.getDefaultMessage());
        });
        
        Map<String, Object> response = new HashMap<>();
        response.put("code", 400);
        response.put("message", "参数校验失败");
        response.put("errors", errors);
        
        return ResponseEntity.badRequest().body(response);
    }
    
    // 3. 处理资源不存在异常
    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<Map<String, Object>> handleResourceNotFoundException(
            ResourceNotFoundException ex) {
        
        Map<String, Object> response = new HashMap<>();
        response.put("code", 404);
        response.put("message", ex.getMessage());
        
        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(response);
    }
    
    // 4. 处理所有其他异常
    @ExceptionHandler(Exception.class)
    public ResponseEntity<Map<String, Object>> handleException(Exception ex) {
        
        Map<String, Object> response = new HashMap<>();
        response.put("code", 500);
        response.put("message", "服务器内部错误");
        response.put("detail", ex.getMessage());
        
        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR)
                            .body(response);
    }
}
```

```java
// 1. 自定义日志注解
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Log {
    String operation() default "";  // 操作名称
    String module() default "";     // 模块名称
}

// 2. 日志切面
@Aspect
@Component
public class LogAspect {
    
    private static final Logger logger = LoggerFactory.getLogger(LogAspect.class);
    
    @Autowired
    private HttpServletRequest request;
    
    @Around("@annotation(log)")
    public Object logAround(ProceedingJoinPoint joinPoint, Log log) throws Throwable {
        String operation = log.operation();
        String module = log.module();
        
        long startTime = System.currentTimeMillis();
        
        // 记录请求信息
        String className = joinPoint.getTarget().getClass().getSimpleName();
        String methodName = joinPoint.getSignature().getName();
        Object[] args = joinPoint.getArgs();
        
        logger.info("【日志】模块: {}, 操作: {}, 类: {}, 方法: {}, 参数: {}",
                   module, operation, className, methodName, Arrays.toString(args));
        
        try {
            // 执行目标方法
            Object result = joinPoint.proceed();
            
            long endTime = System.currentTimeMillis();
            long executionTime = endTime - startTime;
            
            logger.info("【日志】执行成功, 耗时: {}ms, 结果: {}", 
                       executionTime, result);
            
            return result;
        } catch (Exception e) {
            long endTime = System.currentTimeMillis();
            long executionTime = endTime - startTime;
            
            logger.error("【日志】执行失败, 耗时: {}ms, 异常: {}", 
                        executionTime, e.getMessage());
            
            throw e;
        }
    }
}
```
