12. Java8 新特性详解

学习目标：

  1. 理解并会写 Lambda 表达式。
  2. 熟练使用 Stream API 处理集合数据（开发中最常用）。
  3. 掌握 Optional 避免空指针异常。
  4. 了解 新日期时间 API。

1. Lambda 表达式 (Lambda Expressions)​

核心理念：将代码像数据一样传递。让代码更简洁。

1.1 为什么要用 Lambda？​

在 Java 8 之前，如果我们想把一个简单的行为传递给方法（比如线程的 Runnable，或者排序的 Comparator），需要写繁琐的匿名内部类。

对比示例：

// 【老写法】匿名内部类
new Thread(new Runnable() {
    @Override
    public void run() {
        System.out.println("Old style thread!");
    }
}).start();

// 【新写法】Lambda 表达式
new Thread(() -> System.out.println("New style thread!")).start();

1.2 语法规则​

(参数列表) -> { 方法体 }
  1. 左侧：参数列表。如果只有一个参数，小括号 () 可以省略；如果没有参数，必须写 ()。
  2. 中间：-> 箭头操作符。
  3. 右侧：方法体。如果只有一行代码，大括号 {} 和分号 ; 可以省略；如果是 return 语句，return 关键字也可以省略。

1.3 方法引用 (Method Reference)​

当 Lambda 表达式的方法体仅仅是调用一个现有的方法时，可以使用 :: 简化。

// Lambda 写法
list.forEach(s -> System.out.println(s));

// 方法引用写法 (更简洁)
list.forEach(System.out::println);

2. 函数式接口 (Functional Interfaces)​

定义：只包含一个抽象方法的接口。Lambda 表达式就是函数式接口的实例。

Java 内置了四大核心函数式接口（位于 java.util.function 包），你需要记住它们，因为 Stream API 全是基于它们的：

接口类型参数返回值用途常用方法
Consumer<T>(消费型)Tvoid给你一个对象，你把它“消费”掉（比如打印、存库）accept(T t)
Supplier<T>(供给型)无T不需要参数，凭空给你变出一个对象（比如工厂模式）get()
Function<T, R>(函数型)TR输入 T，转换后返回 R（比如 String 转 Integer）apply(T t)
Predicate<T>(断言型)Tboolean判断 T 是否满足条件，返回真/假（比如过滤）test(T t)

3. Stream API (流式编程) —— 重中之重​

核心理念：对集合（Collection）及其元素进行类似 SQL 的操作（过滤、映射、聚合）。

注意：Stream 不存储数据，不改变源数据，且是延迟执行的。

Stream 操作分为三步：

  1. 创建流：从集合或数组获取流。
  2. 中间操作 (Intermediate)：链式处理（过滤、转换...），返回流本身。
  3. 终止操作 (Terminal)：产生结果（List、int、void...），流随之关闭。

3.1 常用操作演示​

假设有一个 User 类列表：List<User> users。

A. 筛选与切片 (Filtering & Slicing)​

// 找出年龄大于 18 岁的用户
users.stream()
     .filter(u -> u.getAge() > 18) // Predicate: 返回 true 留下
     .forEach(System.out::println); // 终止操作

// 跳过前 2 个，再取前 3 个 (分页常用)
users.stream()
     .skip(2)
     .limit(3)
     .forEach(System.out::println);

B. 映射 (Mapping)​

把流中的元素“变身”成另一种形式。

// 只要用户的名字，不要整个 User 对象
List<String> names = users.stream()
                          .map(User::getName) // Function: User -> String
                          .collect(Collectors.toList()); // 收集结果

C. 排序 (Sorting)​

// 按年龄从大到小排序
users.stream()
     .sorted((u1, u2) -> u2.getAge() - u1.getAge()) // Comparator
     .forEach(System.out::println);

D. 终止操作：归约与收集 (Reducing & Collecting)​

这是最后一步，必须有，否则中间操作不会执行！

// 1. collect: 转为 List, Set, Map
List<User> resultList = stream.collect(Collectors.toList());
Set<User> resultSet = stream.collect(Collectors.toSet());

// 2. count: 统计个数
long count = users.stream().filter(u -> u.getAge() > 18).count();

// 3. findFirst / findAny: 查找
Optional<User> first = users.stream().findFirst();

4. Optional 类​

核心理念：优雅地解决 NullPointerException (空指针异常)。

Optional 是一个容器对象，它可能包含值，也可能为空。

不要再写这样的代码了：

if (user != null) {
    if (user.getAddress() != null) {
        System.out.println(user.getAddress().getCity());
    }
}

使用 Optional 优化：

// 创建
Optional<String> opt = Optional.ofNullable(str);

// 判断并执行
opt.ifPresent(s -> System.out.println(s));

// 如果有值则返回，没值则返回默认值 (常用)
String finalStr = opt.orElse("Default Value");

// 如果有值则返回，没值则抛异常
String result = opt.orElseThrow(() -> new RuntimeException("值不存在"));

5. 新日期时间 API (Java 8 Date/Time)​

位置：java.time 包 特点：线程安全（不可变），API 设计更清晰。

  • LocalDate: 只包含日期 (yyyy-MM-dd)
  • LocalTime: 只包含时间 (HH:mm:ss)
  • LocalDateTime: 日期 + 时间
  • DateTimeFormatter: 格式化与解析

常用操作：

// 获取当前时间
LocalDateTime now = LocalDateTime.now();

// 自定义创建
LocalDate date = LocalDate.of(2025, 12, 21);

// 格式化 (Date -> String)
DateTimeFormatter dtf = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String str = now.format(dtf);

// 解析 (String -> Date)
LocalDateTime parsed = LocalDateTime.parse("2025-12-21 10:00:00", dtf);

// 时间计算 (非常方便)
LocalDateTime tomorrow = now.plusDays(1); // 加一天
LocalDateTime lastMonth = now.minusMonths(1); // 减一个月

6. (扩展) Java 10 - 17 新特性速览​

虽然重点是 Java 8，但现代开发中经常会用到以下新特性，了解一下即可：

  1. var 局部变量类型推断 (Java 10): 
    // 编译器会自动推断 list 是 ArrayList<String> 类型
    var list = new ArrayList<String>(); 
    var str = "Hello";
  2. 文本块 Text Blocks (Java 13/15): 不用再写丑陋的 \n 和 + 拼接 SQL 或 HTML 了。 
    String sql = """
                 SELECT * 
                 FROM user 
                 WHERE id = 1
                 """;
  3. Record (记录类) (Java 14/16): 快速定义只存数据的类（像 Lombok 的 @Data）。 
    // 自动生成构造器、getter、equals、hashCode、toString
    public record User(String name, int age) {}
