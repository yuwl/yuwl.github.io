6. 面向对象高级特性

学习目标：

  1. 理解 static 和 final 的具体应用场景。
  2. 彻底搞懂 抽象类与接口的区别（面试必考）。
  3. 掌握匿名内部类的写法（为 Lambda 表达式打基础）。

1. static 关键字 (静态)​

一句话理解：static 修饰的东西属于类，不属于某个具体的对象。它是所有对象共享的。

1.1 静态变量 (static field)​

  • 特点：内存中只有一份，被该类的所有对象共享。
  • 场景：用于定义常量、计数器等公用数据。
public class Student {
    public String name; // 实例变量：每个学生名字不同
    public static String school = "清华大学"; // 静态变量：所有学生都在一个学校

    public Student(String name) {
        this.name = name;
    }
}

// 测试
public class Test {
    public static void main(String[] args) {
        Student s1 = new Student("张三");
        Student s2 = new Student("李四");

        // 推荐用 类名.变量名 访问
        System.out.println(Student.school); // 输出：清华大学
        
        // 如果修改静态变量，所有对象都会受到影响
        Student.school = "北京大学";
        System.out.println(s1.school); // 输出：北京大学
        System.out.println(s2.school); // 输出：北京大学
    }
}

1.2 静态方法 (static method)​

  • 特点：不需要 new 对象，直接用 类名.方法名() 调用。
  • 限制：静态方法中不能直接访问非静态成员（因为静态加载时，对象还没出生）。
  • 场景：工具类的方法（如 Math.random(), Arrays.sort()）。
public class MathUtils {
    // 工具方法通常设为 static
    public static int add(int a, int b) {
        return a + b;
    }
}

// 调用时非常方便，不需要 new MathUtils()
int sum = MathUtils.add(10, 20);

1.3 静态代码块​

  • 特点：类加载时执行，只执行一次。
  • 场景：复杂的静态数据初始化（如读取配置文件、加载驱动）。

2. final 关键字 (最终)​

一句话理解：final 意味着不可改变。

修饰位置含义举例
修饰类太监类：该类不能被继承String 类、Math 类都是 final 的
修饰方法最终方法：该方法不能被子类重写核心业务逻辑不想被修改时
修饰变量常量：值只能被赋值一次，之后不可改final double PI = 3.14;

注意：如果 final 修饰的是引用类型（如数组、对象），是指引用地址不可变，但对象内部的数据是可以改的。

3. 抽象类 (Abstract Class)​

一句话理解：它是模板。父类知道大概要做什么，但具体怎么做如果不确定，就定义为抽象。

  • 语法：使用 abstract 关键字。
  • 规则：
    1. 抽象类不能实例化（不能 new）。
    2. 抽象类中可以有抽象方法（只有方法签名，没有方法体 {}），也可以有普通方法。
    3. 子类继承抽象类，必须重写所有抽象方法，除非子类也是抽象类。
// 定义一个抽象类：动物
abstract class Animal {
    // 普通方法：所有动物都会呼吸
    public void breathe() {
        System.out.println("呼吸空气...");
    }

    // 抽象方法：吃什么？不知道，由具体动物决定
    public abstract void eat(); 
}

class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("狗吃骨头");
    }
}

class Cat extends Animal {
    @Override
    public void eat() {
        System.out.println("猫吃鱼");
    }
}

4. 接口 (Interface) —— 核心中的核心​

一句话理解：它是契约（Contract）或标准。它定义了“你能干什么”，而不关心“你是谁”。

  • 语法：使用 interface 定义，使用 implements 实现。
  • 特点：
    1. 接口中的方法默认是 public abstract (JDK 8 之前)。
    2. 接口中的变量默认是 public static final (常量)。
    3. 一个类可以实现多个接口 (Java 是单继承，多实现)。

4.1 代码示例：USB 接口标准​

// 定义 USB 接口标准
interface USB {
    void connect(); // 连接
    void transfer(); // 传输数据
}

// 鼠标实现 USB 标准
class Mouse implements USB {
    @Override
    public void connect() {
        System.out.println("鼠标已连接");
    }
    @Override
    public void transfer() {
        System.out.println("鼠标传输移动信号");
    }
}

// 键盘实现 USB 标准
class Keyboard implements USB {
    @Override
    public void connect() {
        System.out.println("键盘已连接");
    }
    @Override
    public void transfer() {
        System.out.println("键盘传输打字信号");
    }
}

// 电脑：我不管你是什么，只要实现了 USB 接口我就能用
class Computer {
    public void useDevice(USB device) { // 多态的应用
        device.connect();
        device.transfer();
    }
}

4.2 抽象类 vs 接口 (面试必背)​

特性抽象类 (Abstract Class)接口 (Interface)
关键字extendsimplements
关系Is-a (是不是)：狗是动物Has-a / Can-do (能不能)：狗会跑
构造器有，给子类初始化用无
多继承只能继承一个可以实现多个
成员变量各种类型都可以只能是常量 (public static final)
设计目的代码复用 (模板模式)定义规范/解耦 (策略模式)

5. 内部类 (Inner Class)​

重点：初学者只需要掌握 匿名内部类，其他的（成员内部类、局部内部类）了解即可。

匿名内部类 (Anonymous Inner Class)​

  • 场景：如果一个接口/抽象类只需要用一次，不想专门为了它创建一个 .java 文件，就可以使用匿名内部类。
  • 地位：它是 Java 8 Lambda 表达式的前身。
interface Swim {
    void swimming();
}

public class TestInner {
    public static void main(String[] args) {
        // 常规写法：先定义一个类实现 Swim，然后 new 出来
        
        // 匿名内部类写法：直接 new 接口，并当场实现方法
        Swim s = new Swim() {
            @Override
            public void swimming() {
                System.out.println("匿名内部类：我在游泳...");
            }
        }; // 注意这里有分号
        
        s.swimming();
        
        // 进阶：通常作为参数直接传递
        testSwim(new Swim() {
            @Override
            public void swimming() {
                System.out.println("作为参数传递的匿名内部类");
            }
        });
    }

    public static void testSwim(Swim s) {
        s.swimming();
    }
}

📝 阶段二练习任务​

  1. Static 练习：编写一个 User 类，统计目前一共创建了多少个 User 对象（提示：使用 static 计数器，在构造方法中自增）。
  2. 接口练习：
    • 定义一个 Payment 接口，包含 pay(double money) 方法。
    • 编写 AliPay 和 WeChatPay 两个类实现该接口。
    • 编写一个 Shop 类，包含方法 buy(Payment p, double money)，测试用不同的支付方式付款。
  3. Debug 体验：在接口的多态调用处打断点，观察代码实际跳到了哪个子类的实现中。

下一步建议： 当你熟悉了接口和多态，恭喜你，你已经迈过了 Java 入门最难的门槛。接下来的 API 学习 (集合、IO) 会更加具体和实用。
