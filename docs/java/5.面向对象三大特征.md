

# 5. 面向对象三大特征

核心理念：将现实世界中的事物抽象为“对象”，通过封装保护数据，通过继承复用代码，通过多态增加程序的灵活性。

---

## 1. 封装 (Encapsulation)

> 一句话理解：把自己关在屋子里，只留一扇门。在这个屋子里你可以随意折腾，外面的人只能通过那扇门和你交流，且必须遵守你的规则。

### 1.1 为什么要封装？
如果不封装，任何人都可以随意修改对象的数据，这很不安全。
例如：`User` 对象的年龄被错误地设置为 `-100`。

### 1.2 核心实现步骤
1.  使用 `private` 关键字修饰成员变量（属性），使其在类外部不可见。
2.  提供 `public` 的 Getter (获取值) 和 Setter (设置值) 方法，用于对外暴露数据的访问和修改入口。

### 1.3 代码演示

```java
public class Student {
    // 1. 属性私有化 (Private)
    private String name;
    private int age;

    // 2. 提供公共的 Setter 方法 (用于赋值，可以在这里加逻辑判断)
    public void setAge(int age) {
        if (age > 0 && age < 120) {
            this.age = age;
        } else {
            System.out.println("❌ 年龄输入不合法！已重置为默认值 18");
            this.age = 18;
        }
    }

    // 3. 提供公共的 Getter 方法 (用于获取值)
    public int getAge() {
        return this.age;
    }

    // name 的 getter/setter (通常由 IDE 快捷键 Alt+Insert 自动生成)
    public void setName(String name) {
        this.name = name;
    }
    public String getName() {
        return this.name;
    }
}

// 测试类
class Test {
    public static void main(String[] args) {
        Student s = new Student();
        // s.age = -50; // ❌ 报错！无法直接访问 private 属性
        
        s.setAge(-50);  // ✅ 通过方法访问，触发内部逻辑检查
        System.out.println("学生年龄: " + s.getAge()); // 输出: 学生年龄: 18
    }
}
```

### 🎯 学习重点
*   `private`: 只能在本类中访问。
*   `this` 关键字: 代表当前对象的引用（即谁调用这个方法，this 就是谁）。

## 2. 继承 (Inheritance)

> 一句话理解：子承父业。儿子自动拥有父亲所有的财产（非私有属性和方法），并且还可以发展自己的新技能。

### 2.1 为什么要继承？
为了代码复用。如果 `Cat` 类和 `Dog` 类都有 `eat()` 和 `sleep()` 方法，没必要写两遍，直接提取出一个 `Animal` 父类即可。

### 2.2 核心语法
*   `extends`: 用于继承一个类。
*   Java 是单继承的：一个子类只能有一个直接父类（一个儿子只能有一个亲爹）。

### 2.3 代码演示

```java
// 父类 (基类)
class Animal {
    String name;

    public void eat() {
        System.out.println(name + " 正在吃东西...");
    }
}

// 子类 (派生类) 继承了 Animal
class Dog extends Animal {
    // 独有的方法
    public void bark() {
        System.out.println(name + " 汪汪叫！");
    }
}

class TestInheritance {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.name = "旺财";
        
        // eat() 方法在 Dog 类中没写，但是从 Animal 继承过来了
        dog.eat();  // 输出: 旺财 正在吃东西...
        dog.bark(); // 输出: 旺财 汪汪叫！
    }
}
```

### 🎯 学习重点
*   `super` 关键字: 用于调用父类的属性、方法或构造器。
*   方法重写 (Override): 子类不满意父类的方法，自己重写一个同名同参的方法。注意要加 `@Override` 注解。

## 3. 多态 (Polymorphism) —— 难点

> 一句话理解：花木兰替父从军。
> *   表面看：她是她父亲（花弧），因为名册上写的是花弧的名字（父类引用）。
> *   实际看：她是花木兰（子类对象）。
> *   行为：打仗时，她表现出的是花木兰的武艺（执行子类重写的方法）。

### 3.1 多态的三个必要条件
1.  继承：必须存在父子类关系。
2.  重写：子类必须重写父类的方法。
3.  向上转型：父类引用指向子类对象。

### 3.2 核心语法
```java
Animal a = new Dog(); // 重点在这里！
```

### 3.3 代码演示

```java
// 1. 继承
class Animal {
    public void sound() {
        System.out.println("动物发出叫声");
    }
}

class Cat extends Animal {
    // 2. 重写
    @Override
    public void sound() {
        System.out.println("喵喵喵~");
    }
}

class Dog extends Animal {
    @Override
    public void sound() {
        System.out.println("汪汪汪!");
    }
}

public class TestPolymorphism {
    public static void main(String[] args) {
        // 3. 向上转型 (多态的核心)
        Animal myAnimal = new Cat(); 
        myAnimal.sound(); // 输出: 喵喵喵~ (自动调用了 Cat 的方法)

        // 改变引用指向
        myAnimal = new Dog();
        myAnimal.sound(); // 输出: 汪汪汪! (变成了 Dog 的行为)
        
        // ❌ 错误演示
        // myAnimal.catchMouse(); // 报错！因为 Animal 类里没有抓老鼠的方法。
        // 多态的弊端：无法调用子类特有的方法。
    }
}
```

### 3.4 多态有什么用？
解耦。看下面的例子，如果不使用多态，每增加一种动物，`FeedMaster` 的代码就要修改一次。

```java
class FeedMaster {
    // 不需要写 feed(Dog d) 和 feed(Cat c)
    // 只需要写一个 feed(Animal a)
    // 无论以后来了 Pig, Tiger, 只要是 Animal 的子类，这个方法都能接收！
    public void feed(Animal a) {
        System.out.println("喂食开始...");
        a.sound(); // 不同的动物会发出不同的声音
    }
}
```

## 💡 总结与面试高频考点

| 特征 | 关键字 | 作用 | 记忆口诀 |
| :--- | :--- | :--- | :--- |
| 封装 | `private`, getter/setter | 保护数据，隐藏细节 | 属性私有化，方法公开化 |
| 继承 | `extends`, `super` | 代码复用，扩展功能 | 子承父业，单继承 |
| 多态 | `Parent p = new Child()` | 灵活，解耦 | 编译看左边(父)，运行看右边(子) |

### 🛑 常见避坑指南
1.  构造器不能被继承：子类不能继承父类的构造器，但子类构造器第一行默认会调用 `super()` (父类的无参构造器)。
2.  Overload vs Override：
    *   重载 (Overload): 同一个类中，方法名相同，参数列表不同（与多态无关）。
    *   重写 (Override): 子类覆盖父类方法，方法名、参数必须完全一样（多态的基础）。
3.  多态的局限性：多态情况下，只能调用父类中有的方法。如果想调用子类特有的方法，必须进行向下转型 (强制类型转换 `Dog d = (Dog) a;`)。
