19. 持久层框架

核心目标：掌握 MyBatis，让数据库操作像调用方法一样简单。不再手写繁琐的 SQL 连接代码，专注于业务逻辑。

1. 为什么要用持久层框架？​

回看 JDBC 的代码，你会发现几个痛点：

  • 代码重复: 每次操作数据库都要写 DriverManager.getConnection()、pstmt.setInt()、rs.getString()。
  • 映射繁琐: 需要手动把 ResultSet 中的数据一个个取出来，再赋值给 Java 对象。
  • SQL 散落: SQL 语句写在 Java 代码里，维护困难。

持久层框架正是为了解决这些问题而生：

  • ORM (Object-Relational Mapping): 自动把数据库表映射成 Java 对象，把 Java 对象映射成数据库记录。
  • 方法化调用: 定义一个接口方法 User findById(Integer id)，框架自动帮你生成实现，执行 SQL，返回结果。
  • 配置化: SQL 写在 XML 或注解中，与 Java 代码分离。

2. MyBatis 简介​

MyBatis 是一款优秀的半自动 ORM 框架，也是目前 Java 持久层框架的主流选择：

2.1 MyBatis 的特点​

  • 半自动: 你需要自己写 SQL，但不需要手写 JDBC 代码。
  • 灵活: 对于复杂 SQL（如多表关联查询、存储过程），手写 SQL 更容易控制。
  • 轻量级: 学习成本低，上手快。
  • 经典: 老项目和很多大公司仍在使用，社区活跃。

2.2 MyBatis vs Hibernate (了解即可)​

特性MyBatisHibernate
SQL 编写需要自己写 SQL（灵活）自动生成 SQL（全自动）
复杂查询优势，手写 SQL 更容易劣势，复杂查询较困难
学习曲线较低较高
性能优化容易优化（手动控制 SQL）较难优化（自动生成 SQL）
适用场景复杂业务、报表系统简单 CRUD 系统

结论: 在国内企业开发中，MyBatis 是主流选择。本教程专注讲解 MyBatis，等你掌握了 MyBatis 后，可以再学习 MyBatis-Plus（MyBatis 的增强工具）。

2.3 学习路径建议​

第1阶段：传统 MyBatis（本章节）
    └─ 理解核心原理，掌握 Mapper、XML、动态 SQL

第2阶段：Spring Boot 整合 MyBatis
    └─ 体验自动化配置的便利（第 20 章）

第3阶段：MyBatis-Plus（进阶）
    └─ 使用增强工具，大幅提升开发效率

重要提示: 本章节采用传统方式讲解，不依赖 Spring Boot。等你掌握了 MyBatis 核心概念后，再学 Spring Boot 会发现整合非常简单。

3. 快速上手 MyBatis (传统方式)​

学习路径: 本章采用传统方式讲解 MyBatis，不依赖 Spring Boot。等你掌握了 MyBatis 核心概念后，再学 Spring Boot 会发现整合非常简单。

3.1 环境准备 (Maven 项目)​

假设你已经掌握了 Maven（参考第 15 章），创建一个标准的 Maven 项目结构：

mybatis-demo
├── src
│   ├── main
│   │   ├── java
│   │   │   └── com.example.demo
│   │   ├── resources
│   │   │   ├── mybatis-config.xml    # MyBatis 核心配置文件
│   │   │   └── mapper                # SQL 映射文件目录
│   │   │       └── UserMapper.xml
│   └── test
└── pom.xml

步骤 1: 添加依赖​

在 pom.xml 中添加 MyBatis 和 MySQL 驱动：

<dependencies>
    <!-- MyBatis 核心依赖 -->
    <dependency>
        <groupId>org.mybatis</groupId>
        <artifactId>mybatis</artifactId>
        <version>3.5.16</version>
    </dependency>

    <!-- MySQL 驱动 -->
    <dependency>
        <groupId>mysql</groupId>
        <artifactId>mysql-connector-j</artifactId>
        <version>8.0.33</version>
    </dependency>

    <!-- 日志框架 (可选，用于查看 SQL 执行日志) -->
    <dependency>
        <groupId>log4j</groupId>
        <artifactId>log4j</artifactId>
        <version>1.2.17</version>
    </dependency>
</dependencies>

步骤 2: 创建 MyBatis 配置文件​

在 src/main/resources 下创建 mybatis-config.xml：

<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-config.dtd">

<configuration>
    <!-- 配置环境 (development: 开发环境) -->
    <environments default="development">
        <environment id="development">
            <!-- 事务管理器: JDBC 表示使用 JDBC 的事务管理 -->
            <transactionManager type="JDBC"/>

            <!-- 数据源: POOLED 表示使用连接池 -->
            <dataSource type="POOLED">
                <property name="driver" value="com.mysql.cj.jdbc.Driver"/>
                <property name="url" value="jdbc:mysql://localhost:3306/test_db?useSSL=false&amp;serverTimezone=Asia/Shanghai&amp;characterEncoding=utf8"/>
                <property name="username" value="root"/>
                <property name="password" value="123456"/>
            </dataSource>
        </environment>
    </environments>

    <!-- 注册 Mapper 映射文件 -->
    <mappers>
        <mapper resource="mapper/UserMapper.xml"/>
    </mappers>
</configuration>

说明: 在传统方式中，我们需要手动配置数据库连接信息。而在 Spring Boot 中，这些配置会大大简化。

4. MyBatis 核心开发流程​

4.1 实体类 (Entity) / 数据传输对象 (DTO)​

假设数据库有一张 user 表：

CREATE TABLE user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL,
    age INT,
    email VARCHAR(100)
);

创建对应的实体类（纯 POJO，不需要任何注解）：

package com.example.demo.entity;

public class User {
    private Long id;
    private String username;
    private Integer age;
    private String email;

    // 快速生成 Getter/Setter/toString (IDEA 快捷键: Alt+Insert)
    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }

    public String getUsername() { return username; }
    public void setUsername(String username) { this.username = username; }

    public Integer getAge() { return age; }
    public void setAge(Integer age) { this.age = age; }

    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }

    @Override
    public String toString() {
        return "User{id=" + id + ", username='" + username + "', age=" + age + ", email='" + email + "'}";
    }
}

4.2 Mapper 接口​

定义 Mapper 接口，包含你的数据库操作方法：

package com.example.demo.mapper;

import com.example.demo.entity.User;
import java.util.List;

// 接口方法（不需要任何注解）
public interface UserMapper {

    // 根据ID查询
    User findById(Long id);

    // 查询全部
    List<User> findAll();

    // 根据用户名查询
    User findByUsername(String username);

    // 新增用户
    int insert(User user);

    // 更新用户
    int update(User user);

    // 根据ID删除
    int deleteById(Long id);

    // 条件查询：根据年龄范围
    List<User> findByAgeRange(Integer minAge, Integer maxAge);
}

4.3 XML 映射文件​

在 src/main/resources/mapper/ 目录下创建 UserMapper.xml：

<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">

<!-- namespace 必须对应 Mapper 接口的全限定名 -->
<mapper namespace="com.example.demo.mapper.UserMapper">

    <!-- 定义结果映射 (resultMap)，将数据库字段映射到 Java 对象 -->
    <resultMap id="UserResultMap" type="com.example.demo.entity.User">
        <id property="id" column="id"/>
        <result property="username" column="username"/>
        <result property="age" column="age"/>
        <result property="email" column="email"/>
    </resultMap>

    <!-- 1. 根据ID查询 -->
    <select id="findById" resultMap="UserResultMap">
        SELECT * FROM user WHERE id = #{id}
    </select>

    <!-- 2. 查询全部 -->
    <select id="findAll" resultMap="UserResultMap">
        SELECT * FROM user
    </select>

    <!-- 3. 根据用户名查询 -->
    <select id="findByUsername" resultMap="UserResultMap">
        SELECT * FROM user WHERE username = #{username}
    </select>

    <!-- 4. 新增用户 -->
    <!-- useGeneratedKeys: 使用数据库生成的主键 -->
    <!-- keyProperty: 将生成的主键值赋值给对象的哪个属性 -->
    <insert id="insert" useGeneratedKeys="true" keyProperty="id">
        INSERT INTO user (username, age, email)
        VALUES (#{username}, #{age}, #{email})
    </insert>

    <!-- 5. 更新用户 -->
    <update id="update">
        UPDATE user
        SET username = #{username},
            age = #{age},
            email = #{email}
        WHERE id = #{id}
    </update>

    <!-- 6. 根据ID删除 -->
    <delete id="deleteById">
        DELETE FROM user WHERE id = #{id}
    </delete>

    <!-- 7. 条件查询：根据年龄范围 -->
    <select id="findByAgeRange" resultMap="UserResultMap">
        SELECT * FROM user
        WHERE age BETWEEN #{minAge} AND #{maxAge}
    </select>

</mapper>

关键点:

  • namespace: 必须等于 Mapper 接口的全限定名
  • id: SQL 语句的 id 必须等于接口方法名
  • resultMap: 定义数据库列与 Java 对象属性的映射关系
  • #: 预编译参数占位符，防止 SQL 注入

5. 使用 MyBatis 操作数据库​

5.1 获取 SqlSession（传统方式）​

在传统方式中，你需要手动获取 SqlSession 对象来执行数据库操作：

import org.apache.ibatis.io.Resources;
import org.apache.ibatis.session.SqlSession;
import org.apache.ibatis.session.SqlSessionFactory;
import org.apache.ibatis.session.SqlSessionFactoryBuilder;

import java.io.IOException;
import java.io.InputStream;

public class MyBatisUtil {

    private static SqlSessionFactory sqlSessionFactory;

    // 静态代码块，初始化 SqlSessionFactory（只需执行一次）
    static {
        try {
            // 读取配置文件
            String resource = "mybatis-config.xml";
            InputStream inputStream = Resources.getResourceAsStream(resource);
            // 构建 SqlSessionFactory
            sqlSessionFactory = new SqlSessionFactoryBuilder().build(inputStream);
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // 获取 SqlSession
    public static SqlSession getSqlSession() {
        return sqlSessionFactory.openSession(); // 默认手动提交事务
    }
}

5.2 CRUD 操作示例​

import com.example.demo.entity.User;
import com.example.demo.mapper.UserMapper;
import com.example.demo.util.MyBatisUtil;
import org.apache.ibatis.session.SqlSession;

public class UserDaoTest {

    public static void main(String[] args) {
        // 使用 try-with-resources 自动关闭 SqlSession
        try (SqlSession sqlSession = MyBatisUtil.getSqlSession()) {

            // 获取 Mapper 接口代理对象
            UserMapper mapper = sqlSession.getMapper(UserMapper.class);

            // ========== 1. 新增用户 ==========
            User newUser = new User();
            newUser.setUsername("张三");
            newUser.setAge(25);
            newUser.setEmail("zhangsan@example.com");

            int insertResult = mapper.insert(newUser);
            System.out.println("新增受影响行数: " + insertResult);
            System.out.println("新增后的用户（主键已自动回填）: " + newUser);

            // ========== 2. 查询全部 ==========
            System.out.println("\n所有用户:");
            mapper.findAll().forEach(System.out::println);

            // ========== 3. 根据ID查询 ==========
            System.out.println("\n根据ID查询用户:");
            User userById = mapper.findById(1L);
            System.out.println(userById);

            // ========== 4. 根据用户名查询 ==========
            System.out.println("\n根据用户名查询:");
            User userByName = mapper.findByUsername("张三");
            System.out.println(userByName);

            // ========== 5. 条件查询：年龄范围 ==========
            System.out.println("\n年龄在 20-30 之间的用户:");
            mapper.findByAgeRange(20, 30).forEach(System.out::println);

            // ========== 6. 更新用户 ==========
            System.out.println("\n更新用户:");
            userById.setAge(26);
            userById.setEmail("newemail@example.com");
            int updateResult = mapper.update(userById);
            System.out.println("更新受影响行数: " + updateResult);

            // ========== 7. 根据ID删除 ==========
            // int deleteResult = mapper.deleteById(1L);
            // System.out.println("删除受影响行数: " + deleteResult);

            // ========== 提交事务 ==========
            sqlSession.commit(); // 注意：手动提交事务！
        }
    }
}

5.3 事务管理说明​

在传统 MyBatis 中：

  • 默认情况下，不会自动提交事务。
  • 你需要调用 sqlSession.commit() 手动提交事务。
  • 如果发生异常，可以调用 sqlSession.rollback() 回滚事务。

示例：

try (SqlSession sqlSession = MyBatisUtil.getSqlSession()) {
    UserMapper mapper = sqlSession.getMapper(UserMapper.class);

    try {
        // 执行多个数据库操作
        mapper.insert(user1);
        mapper.insert(user2);

        // 所有操作成功，提交事务
        sqlSession.commit();
    } catch (Exception e) {
        // 发生异常，回滚事务
        sqlSession.rollback();
        e.printStackTrace();
    }
}

6. 动态 SQL​

MyBatis 的强大之处在于动态 SQL，可以根据条件动态拼接 SQL 语句。

6.1 <if> 标签 - 条件判断​

根据参数是否存在，决定是否拼接某个条件：

<!-- Mapper 接口方法 -->
List<User> searchUsers(String username, Integer minAge, Integer maxAge);

<!-- XML 映射 -->
<select id="searchUsers" resultMap="UserResultMap">
    SELECT * FROM user
    <where>
        <!-- 如果 username 不为空，则拼接此条件 -->
        <if test="username != null and username != ''">
            AND username LIKE CONCAT('%', #{username}, '%')
        </if>

        <!-- 如果 minAge 不为空，则拼接此条件 -->
        <if test="minAge != null">
            AND age >= #{minAge}
        </if>

        <!-- 如果 maxAge 不为空，则拼接此条件 -->
        <if test="maxAge != null">
            AND age <= #{maxAge}
        </if>
    </where>
</select>

说明: <where> 标签会自动处理 AND 前缀问题，避免生成 WHERE AND ... 这样的错误 SQL。

6.2 <choose>、<when>、<otherwise> - 多选一​

类似于 Java 的 if-else if-else：

<select id="searchUsers" resultMap="UserResultMap">
    SELECT * FROM user
    <where>
        <choose>
            <when test="username != null and username != ''">
                username LIKE CONCAT('%', #{username}, '%')
            </when>
            <when test="email != null and email != ''">
                email = #{email}
            </when>
            <otherwise>
                age >= 18  <!-- 默认条件 -->
            </otherwise>
        </choose>
    </where>
</select>

6.3 <foreach> - 循环批量操作​

常用于批量插入或 IN 查询：

<!-- 批量插入 -->
<insert id="batchInsert">
    INSERT INTO user (username, age, email) VALUES
    <foreach collection="list" item="user" separator=",">
        (#{user.username}, #{user.age}, #{user.email})
    </foreach>
</insert>

<!-- 根据 ID 列表查询 (IN 查询) -->
<select id="findByIds" resultMap="UserResultMap">
    SELECT * FROM user
    WHERE id IN
    <foreach collection="ids" item="id" open="(" separator="," close=")">
        #{id}
    </foreach>
</select>

6.4 <set> - 动态更新​

用于动态更新字段，自动处理末尾逗号：

<update id="updateSelective">
    UPDATE user
    <set>
        <if test="username != null and username != ''">
            username = #{username},
        </if>
        <if test="age != null">
            age = #{age},
        </if>
        <if test="email != null and email != ''">
            email = #{email},
        </if>
    </set>
    WHERE id = #{id}
</update>

7. MyBatis 核心概念详解​

7.1 Mapper 接口与 XML 的映射关系​

配置项说明
namespaceXML 中的 namespace 必须等于 Mapper 接口的全限定类名
idSQL 语句的 id 必须等于接口方法名
parameterType参数类型（可省略，MyBatis 会自动推断）
resultType直接指定返回结果的完全限定类名（适合单表简单映射）
resultMap定义复杂的映射规则（适合多表关联、字段名不一致等情况）

7.2 #{} vs ${} (面试高频)​

#{}${}
本质预编译参数占位符 (?)直接字符串拼接
安全安全，防止 SQL 注入不安全，有注入风险
场景绝大多数情况只能用在不支持预编译的地方（如表名、动态排序字段）
示例WHERE id = #{id} -> WHERE id = ?ORDER BY ${field} -> ORDER BY age

记忆口诀: 默认都用 #{}，只有表名、列名等动态字段才用 ${}。

7.3 MyBatis 核心对象​

对象作用生命周期
SqlSessionFactoryBuilder构建 SqlSessionFactory（工厂创建者）方法局部（用完即丢弃）
SqlSessionFactory创建 SqlSession（工厂）应用全局（一个数据库对应一个）
SqlSession执行 SQL、管理事务（相当于 JDBC 的 Connection）请求级别（用完必须关闭）
Mapper ProxyMapper 接口的代理对象（由 sqlSession.getMapper() 生成）与 SqlSession 同生命周期

8. 传统方式 vs Spring Boot 整合​

8.1 传统方式的痛点​

通过前面的学习，你可能已经发现传统方式有几个问题：

  • 配置繁琐: 需要手动配置 mybatis-config.xml
  • SqlSession 管理: 每次都要手动获取和关闭 SqlSession
  • 事务手动管理: 需要手动调用 commit() 和 rollback()
  • Mapper 获取繁琐: 每次都要调用 sqlSession.getMapper()

8.2 Spring Boot 整合的优势​

当你学习完 Spring Boot 后，你会发现整合 MyBatis 变得极其简单：

  • 自动配置: 只需添加依赖，自动配置数据源和 SqlSessionFactory
  • 注解扫描: @MapperScan 自动扫描 Mapper 接口
  • 依赖注入: 直接 @Autowired 注入 Mapper 接口，无需手动获取
  • 声明式事务: @Transactional 注解自动管理事务
// Spring Boot 方式（对比传统方式）
@Service
public class UserService {
    @Autowired  // 直接注入，无需手动获取 SqlSession
    private UserMapper userMapper;

    @Transactional  // 自动管理事务，无需手动 commit/rollback
    public void register(User user) {
        userMapper.insert(user);
        // 自动提交事务，无需 sqlSession.commit()
    }
}

建议: 现在先掌握 MyBatis 的核心概念（Mapper、XML、动态 SQL），等到学完 Spring Boot 后，你会发现整合非常简单。

  6. 传统方式中如何提交事务？ (调用 sqlSession.commit())

进阶练习​

  1. (动态 SQL) 实现一个灵活的搜索方法：

    // 可选参数：产品名称、金额范围、用户ID
    List<Order> searchOrders(String productName, Double minAmount, Double maxAmount, Long userId);

  2. (批量操作) 实现批量插入订单：

    int batchInsert(List<Order> orders);

  3. (多表关联) 创建 user 表和 order 表，实现联表查询：查询用户及其订单列表：

    <!-- 使用 resultMap 实现一对多映射 -->
    <resultMap id="UserWithOrdersResultMap" type="User">
        <!-- 用户信息 -->
        <id property="id" column="user_id"/>
        <result property="username" column="username"/>
        <!-- 订单列表 (一对多) -->
        <collection property="orders" ofType="Order">
            <id property="id" column="order_id"/>
            <result property="productName" column="product_name"/>
            <result property="amount" column="amount"/>
        </collection>
    </resultMap>
