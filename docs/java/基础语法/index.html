2. 基础语法

学习目标：掌握变量定义、数据类型、运算符以及程序流程控制，能够编写简单的逻辑运算程序。

1. 注释 (Comments)​

代码写给机器看，注释写给人看。良好的注释习惯是专业程序员的素养。

  • 单行注释：使用 //，注释当前行。
  • 多行注释：使用 /* ... */，注释多行内容。
  • 文档注释：使用 / ... */，通常用于类或方法的说明，可以生成 API 文档。
public class Demo {
    /
     * 这是文档注释
     * main 是程序的入口
     */
    public static void main(String[] args) {
        // 这是单行注释：打印一句话
        System.out.println("Hello World"); 

        /* 
           这是多行注释
           可以在这里写很多行
        */
    }
}

2. 变量与数据类型​

Java 是强类型语言，这意味着每个变量都必须先声明类型，才能使用。

2.1 变量的定义​

格式：数据类型 变量名 = 值;

int age = 18;          // 声明一个整数
double price = 99.9;   // 声明一个小数

2.2 八大基本数据类型 (Primitive Types)​

这是 Java 语言内置的最小数据单位，必须背下来。

分类类型关键字占用字节说明举例
整数型byte1极小整数 (-128 ~ 127)byte b = 10;
short2短整数short s = 100;
int4默认整数类型 (最常用)int i = 10000;
long8长整数 (需加后缀 L)long n = 9999999L;
浮点型float4单精度 (需加后缀 F)float f = 3.14F;
double8默认小数类型 (精度更高)double d = 3.14159;
字符型char2单引号括起来的单个字符char c = 'A';
布尔型boolean1位只有 true 或 falseboolean isOk = true;

2.3 引用数据类型 - String​

虽然 String 是一个类（Class），但它用得像基本类型一样频繁。

  • 规则：使用双引号 ""。
  • 拼接：使用 + 号可以连接字符串。
String name = "张三";
System.out.println("你好，" + name); // 输出：你好，张三

2.4 类型转换​

  • 自动类型转换（隐式）：小范围数据 -> 大范围数据。
    • int a = 10; double b = a; // b 变成了 10.0
  • 强制类型转换（显式）：大范围数据 -> 小范围数据（可能丢失精度）。
    • 格式：(目标类型) 变量
    • double x = 3.99; int y = (int) x; // y 变成了 3 (直接截断小数，不四舍五入)

3. 运算符 (Operators)​

3.1 算术运算符​

+, -, *, /, % (取模/取余), ++ (自增), -- (自减)

⚠️ 注意事项：

  1. 整数除法：int a = 5; int b = 2; System.out.println(a / b); 结果是 2，而不是 2.5。想要小数必须有浮点数参与：5.0 / 2。
  2. + 的特殊性：如果 + 号两边有一边是字符串，它就变成了字符串连接符。"5" + 2 结果是 "52"。

3.2 关系运算符​

>, <, >=, <=, == (等于), != (不等于)

  • 结果永远是 boolean 类型 (true 或 false)。

3.3 逻辑运算符​

  • && (短路与/并且)：两边都为 true，结果才为 true。
  • || (短路或/或者)：只要有一边为 true，结果就为 true。
  • ! (非/取反)：true 变 false，false 变 true。

💡 "短路"是什么意思？ 对于 A && B，如果 A 已经是 false，不仅结果必为 false，而且程序根本不会去执行 B。这可以提高效率并避免某些错误（如空指针）。

3.4 三元运算符​

格式：条件 ? 结果1 : 结果2

  • 如果条件为 true，取结果1，否则取结果2。
int a = 10, b = 20;
int max = (a > b) ? a : b; // max 的值是 20

4. 流程控制 (Control Flow)​

4.1 分支结构 (if-else / switch)​

if-else (最常用)

int score = 85;
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}

switch (适用于匹配固定值)

int week = 3;
switch (week) {
    case 1:
        System.out.println("周一");
        break; // 别忘了 break，否则会“穿透”继续执行下面的 case
    case 2:
        System.out.println("周二");
        break;
    default:
        System.out.println("未知");
}

4.2 循环结构 (for / while)​

for 循环 (推荐：明确循环次数时)

// 打印 1 到 10
for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}

while 循环 (推荐：不确定循环次数，只知道结束条件时)

int i = 1;
while (i <= 10) {
    System.out.println(i);
    i++; // 别忘了更新条件，否则死循环
}

break 与 continue

  • break: 彻底结束当前循环，跳出循环体。
  • continue: 跳过本次循环剩余代码，直接进入下一次循环。

5. 数组 (Array) - 基础入门​

数组是一个容器，可以存储固定长度、同一类型的多个数据。

5.1 定义与初始化​

// 方式1：动态初始化 (指定长度，内容默认是0或null)
int[] arr1 = new int[5]; 

// 方式2：静态初始化 (直接指定内容)
int[] arr2 = {10, 20, 30, 40};

5.2 访问与遍历​

  • 索引 (Index)：从 0 开始。arr2[0] 是 10。
  • 长度：使用 arr.length 属性。
int[] numbers = {11, 22, 33};

// 修改元素
numbers[0] = 99;

// 遍历数组
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}

❌ 常见报错： ArrayIndexOutOfBoundsException：数组索引越界异常。 例如：数组长度为3，你却访问 numbers[3]（有效索引是 0, 1, 2）。
