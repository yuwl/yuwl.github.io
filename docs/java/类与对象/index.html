4. 类与对象

1. 核心概念：什么是类？什么是对象？​

如果把编程比作“造车”：

  • 类 (Class)：是设计图纸。它规定了车有几个轮子、什么颜色、怎么跑。图纸本身不能开。
  • 对象 (Object)：是根据图纸造出来的实实在在的车。你可以造这辆车（对象A），也可以造那辆车（对象B）。

口诀：类是对象的模板，对象是类的实例。

2. 类的定义 (Class Definition)​

在 Java 中，一个类主要包含两部分：

  1. 属性 (成员变量)：描述事物“有什么” (例如：姓名、年龄、颜色)。
  2. 方法 (成员方法)：描述事物“能做什么” (例如：吃饭、睡觉、跑)。

代码示例：定义一个“学生”类​

创建一个名为 Student.java 的文件：

public class Student {
    // --- 1. 属性 (成员变量) ---
    // 姓名
    String name;
    // 年龄
    int age;
    
    // --- 2. 方法 (行为) ---
    // 学习的方法
    public void study() {
        System.out.println(name + " 正在努力学习 Java！");
    }
    
    // 吃饭的方法
    public void eat() {
        System.out.println("学生吃食堂。");
    }
}

3. 对象的创建与使用​

有了类（图纸），我们就可以在主程序中创建对象（实例）了。

语法公式​

类名 对象名 = new 类名();

代码示例：使用“学生”类​

创建一个名为 StudentTest.java 的文件（包含 main 方法）：

public class StudentTest {
    public static void main(String[] args) {
        // 1. 创建对象 (实例化)
        // 这里的 s1 就是一个具体的学生对象
        Student s1 = new Student();
        
        // 2. 使用对象属性 (赋值与取值)
        // 语法：对象名.属性名
        s1.name = "张三";
        s1.age = 18;
        
        System.out.println("学生姓名：" + s1.name);
        System.out.println("学生年龄：" + s1.age);
        
        // 3. 调用对象方法 (让对象干活)
        // 语法：对象名.方法名()
        s1.study(); // 输出：张三 正在努力学习 Java！
        s1.eat();
        
        // --- 创建另一个对象 ---
        Student s2 = new Student();
        s2.name = "李四";
        // s1 和 s2 是两个独立的人，互不影响
        s2.study(); // 输出：李四 正在努力学习 Java！
    }
}

4. 深入理解：对象在内存中长什么样？(重点)​

理解内存有助于你理解“引用”的概念。

  • 栈内存 (Stack)：存放变量名（引用）。比如上面的 s1。它存的不是对象本身，而是对象在堆中的地址。
  • 堆内存 (Heap)：存放真正的对象数据。比如 new Student() 产生的所有数据（name="张三", age=18）。

比喻：

  • s1 是遥控器 (在栈中)。
  • new Student() 出来的对象是电视机 (在堆中)。
  • s1.study() 就像是用遥控器指挥电视机播放画面。

5. 构造器 (Constructor)​

你可能会觉得，每次创建对象都要 s1.name = "xxx"; s1.age = 18; 太麻烦了。有没有办法在创建对象的时候直接赋值？ 答案是：构造器。

什么是构造器？​

  • 它是一个特殊的方法。
  • 方法名必须和类名完全一致。
  • 没有返回值类型 (连 void 都没有)。
  • 在 new 的时候自动调用。

代码进化：加入构造器​

修改 Student.java:

public class Student {
    String name;
    int age;

    // 1. 无参数构造器 (默认构造器)
    // 如果你不写任何构造器，Java会送你一个空的。但一旦你写了带参的，这个空的就必须手动写出来。
    public Student() {
        System.out.println("无参构造器被调用了！");
    }

    // 2. 带参数构造器 (方便初始化)
    public Student(String n, int a) {
        name = n; // 把传入的 n 赋值给成员变量 name
        age = a;
    }

    public void study() {
        System.out.println(name + " 正在学习");
    }
}

使用构造器​

public static void main(String[] args) {
    // 使用无参构造器
    Student s1 = new Student(); 
    
    // 使用带参构造器 (一行代码完成创建和赋值)
    Student s2 = new Student("王五", 20);
    System.out.println(s2.name); // 输出：王五
}

6. this 关键字​

在上面的带参构造器中，参数名 n 和 a 含义不明确。我们更希望参数名也叫 name 和 age。 但是，如果参数名和成员变量名冲突了，Java 怎么区分？

这时就需要 this。

  • this 代表当前对象自己（谁在调用这个方法，this 就是谁）。

最佳实践写法​

public class Student {
    String name; // 成员变量
    int age;

    public Student(String name, int age) {
        // ❌ 错误写法：name = name; (这是把参数赋给参数自己，毫无意义)
        
        // ✅ 正确写法：
        this.name = name; // 把参数 name 赋值给 当前对象的 name
        this.age = age;
    }
}

任务：设计一个“手机类” (Phone)。

  1. 定义属性：品牌 (brand)、价格 (price)、颜色 (color)。
  2. 定义方法：
    • call(String who): 输出 “正在给 [who] 打电话...”。
    • sendMessage(): 输出 “正在群发短信...”。
  3. 构造器：
    • 提供一个无参构造器。
    • 提供一个包含所有属性的带参构造器，使用 this 赋值。
  4. 测试类：
    • 在 main 方法中创建一个小米手机对象（使用带参构造器）。
    • 修改价格。
    • 调用打电话的方法。
