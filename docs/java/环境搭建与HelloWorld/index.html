1. 环境搭建与 Hello World

学习目标：

  1. 成功安装 JDK（Java 开发工具包）。
  2. 配置好环境变量，让电脑认识 Java 命令。
  3. 安装 IntelliJ IDEA（最好用的 Java 编写软件）。
  4. 编写并运行你的第一行代码。

1. 什么是 JDK？ (了解即可)​

  • JDK (Java Development Kit): Java 开发工具包。你是开发者，所以需要它。它包含了编写、编译和运行 Java 程序所需的一切。
  • JRE (Java Runtime Environment): Java 运行环境。如果你只是玩《我的世界》(Minecraft) Java 版，只装它就够了，但我们要写代码，必须装 JDK。

结论：只需要安装 JDK，它里面已经包含了 JRE。

2. 下载与安装 JDK​

目前企业主流使用的版本是 JDK 8, JDK 17, JDK 21。 推荐版本：JDK 17 LTS (长期支持版)，既稳定又包含新特性，适合学习。

📥 下载步骤​

  1. 访问 Oracle 官网下载页面（或者搜索 "Oracle JDK 17 download"）。
  2. 根据你的电脑系统选择：
    • Windows: 选择 x64 Installer (如果是比较新的电脑)。
    • Mac: 选择 x64 DMG Installer (Intel 芯片) 或 Arm 64 DMG Installer (M1/M2/M3 芯片)。
  3. 下载后双击运行，一路点击 "Next" (下一步) 即可。
  4. 注意：记住你安装的路径（默认通常是 C:\Program Files\Java\jdk-17...），后面配置要用。

3. 配置环境变量 (Windows 必做)​

这是最容易出错的一步，请仔细核对。Mac 用户通常安装后无需配置，或使用 Homebrew 安装。以下以 Windows 10/11 为例：

  1. 打开设置：右键“此电脑” -> “属性” -> “高级系统设置” -> “环境变量”。
  2. 新建系统变量 (JAVA_HOME)：
    • 在“系统变量”区域（下半部分），点击“新建”。
    • 变量名: JAVA_HOME
    • 变量值: 粘贴刚才 JDK 的安装路径 (例如: C:\Program Files\Java\jdk-17)
    • 点击确定。
  3. 修改 Path 变量：
    • 在“系统变量”里找到 Path，选中它，点击“编辑”。
    • 点击“新建”，输入：%JAVA_HOME%\bin
    • 这一步的意思是：告诉系统，去 JDK 的 bin 目录下找 java.exe 等命令。
    • 一路点击“确定”保存所有窗口。

✅ 验证是否成功​

  1. 按 Win + R 键，输入 cmd，回车打开黑窗口（命令行）。
  2. 输入命令：java -version
  3. 如果出现类似 java version "17.0.x" ... 的字样，恭喜你，环境配置成功！
  4. 如果提示“不是内部或外部命令”，请回头检查路径是否填错。

4. 安装 IDE：IntelliJ IDEA​

虽然记事本也能写代码，但我们直接使用现代化的工具。 不要使用 Eclipse，它是上个时代的产物。

  1. 下载：搜索 "IntelliJ IDEA Download"。
  2. 选择版本：下载 Community (社区版)。它是免费的，且功能足够你学完所有基础和 Web 开发。
    • 注意：Ultimate (旗舰版) 是收费的，初学不需要。
  3. 安装：下载 .exe (Win) 或 .dmg (Mac)，一路 Next 安装即可。

5. 编写第一个程序：Hello World​

第一步：创建项目​

  1. 打开 IntelliJ IDEA。
  2. 点击 New Project (新建项目)。
  3. Name: JavaBasics (或者你喜欢的名字)。
  4. Language: 选择 Java。
  5. Build system: 选择 IntelliJ。
  6. JDK: 这里应该会自动识别你刚才安装的 JDK 17，如果没有，点击下拉菜单添加。
  7. 点击 Create。

第二步：创建 Java 文件​

  1. 在左侧项目栏，找到 src 文件夹。
  2. 右键 src -> New -> Java Class。
  3. 输入类名：HelloWorld (首字母大写是规范)。
  4. 回车。

第三步：编写代码​

将以下代码输入到编辑器中（尽量手敲，不要复制，感受语法）：

public class HelloWorld {
    // 这是一个 main 方法，是程序的入口，代码从这里开始执行
    public static void main(String[] args) {
        // 这行代码的作用是在控制台打印输出一句话
        System.out.println("Hello World!");
    }
}

第四步：运行程序​

  1. 代码写完后，你会发现在 public class HelloWorld 或 main 方法左侧有一个绿色的小三角 ▶️。
  2. 点击绿色小三角，选择 Run 'HelloWorld.main()'。
  3. 观察下方的控制台 (Console)，你应该能看到输出： 
    Hello World!

6. 代码深度解析 (必读)​

你刚才写下的代码到底是什么意思？

  1. public class HelloWorld:
    • class: 这是一个“类”，Java 代码也是以“类”为单位组织的。
    • HelloWorld: 类的名字。注意：类名必须和文件名完全一致（HelloWorld.java）。
  2. public static void main(String[] args):
    • 这是 Main 方法。
    • 它是程序的大门（入口）。没有它，程序不知道从哪里开始跑。
    • 格式是固定的，初学阶段先死记硬背下来，或者在 IDEA 里输入 psvm 然后按回车，IDE 会帮你自动生成。
  3. System.out.println("..."):
    • 这是输出语句。
    • ln 的意思是 line (换行)，打印完括号里的内容后自动换一行。
    • IDEA 快捷键：输入 sout 然后按回车。

7. Java 运行原理 (面试常识)​

你写的 .java 文件电脑是看不懂的，它经历了两步：

graph LR
    A[HelloWorld.java] -->|javac 编译| B[HelloWorld.class]
    B -->|java 运行| C[JVM 虚拟机]
    C -->|解释/编译| D[操作系统/CPU]
  1. 编译 (Compile): javac 命令把如果你写的源码 (.java) 翻译成 字节码 (.class)。字节码是给 JVM 看的。
  2. 运行 (Run): java 命令启动 JVM (Java 虚拟机)，JVM 负责把字节码翻译成具体操作系统能懂的机器语言并运行。

跨平台原理：为什么 Java 说 "Write Once, Run Anywhere"？ 因为不同系统（Windows, Linux, Mac）有不同版本的 JVM，但它们都认识同一种 .class 文件。

✅ 本节作业​

  1. 成功在 IDEA 中打印出 "Hello World"。
  2. 修改代码，打印出你的名字和年龄，例如： 
    姓名：张三
    年龄：25岁
    (提示：可以写多行 System.out.println)
  3. 尝试故意把 System 拼写成 system (小写)，看看 IDE 会报什么错？（体验编译错误）。

下一步预告： 当你成功打印出 Hello World 后，下一节我们将学习 变量与数据类型，这会让你的程序拥有“记忆”能力。
