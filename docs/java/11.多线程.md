

# 11. 多线程编程

学习目标：理解线程与进程的区别，掌握创建线程的 3 种方式，理解线程安全问题（并发），学会使用线程池。

---

## 1. 核心概念：进程 vs 线程
> 比喻：
> *   进程 (Process)：像是一个工厂。它有独立的厂区（内存空间），工厂之间相互独立。
> *   线程 (Thread)：像是工厂里的工人。一个工厂里可以有多个工人，他们共享工厂的资源（内存、变量），共同完成任务。

*   并行 (Parallel)：多核 CPU 同时执行多个任务（真正的同时）。
*   并发 (Concurrent)：单核 CPU 快速交替执行多个任务（看起来像同时）。

---

## 2. 线程的创建与启动 (重点)

在 Java 中，启动线程必须调用 `start()` 方法，而不是 `run()` 方法！

### 方式一：继承 `Thread` 类
*   缺点：Java 是单继承，继承了 Thread 就不能继承其他类了。
*   代码示例：
    ```java
    // 1. 定义一个类继承 Thread
    public class MyThread extends Thread {
        @Override
        public void run() {
            // 线程要执行的任务
            for (int i = 0; i < 5; i++) {
                System.out.println("工人A正在搬砖: " + i);
            }
        }
    }

    // main 方法中测试
    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        t1.start(); // 启动线程，JVM 会自动调用 run()
    }
    ```

### 方式二：实现 `Runnable` 接口 (推荐)
*   优点：避免了单继承局限性，适合资源共享。
*   代码示例：
    ```java
    // 1. 实现 Runnable 接口
    public class MyTask implements Runnable {
        @Override
        public void run() {
            for (int i = 0; i < 5; i++) {
                System.out.println(Thread.currentThread().getName() + " 正在工作: " + i);
            }
        }
    }

    // main 方法中测试
    public static void main(String[] args) {
        MyTask task = new MyTask();
        // 2. 创建 Thread 对象，把任务交给它
        Thread t1 = new Thread(task, "线程1号");
        Thread t2 = new Thread(task, "线程2号");
        
        t1.start();
        t2.start();
    }
    ```

### 方式三：实现 `Callable` 接口 (进阶)
*   特点：`run()` 没有返回值，`call()` 有返回值并且可以抛出异常。通常配合 `FutureTask` 使用。

## 3. 线程的生命周期
你需要知道线程不是“一启动就一直跑”的，它有几种状态：

1.  新建 (New): `new Thread()` 之后。
2.  就绪 (Runnable): 调用 `start()` 后，等待 CPU 调度。
3.  运行 (Running): 抢到了 CPU，正在执行代码。
4.  阻塞/等待 (Blocked/Waiting): 比如调用了 `sleep()`，或者在这个锁外面排队。
5.  死亡 (Terminated): `run()` 方法执行结束。

## 4. 线程安全问题 (重难点)
> 场景：三个窗口（3个线程）同时卖 100 张票（共享资源）。如果不加控制，会出现 重票（两张票号一样）或 负数票。

出现问题的原因：
1.  多线程环境。
2.  共享数据。
3.  有多条语句操作共享数据（操作不是原子性的）。

### 解决方案：同步机制 (Synchronization)

#### 方法 A：同步代码块 (`synchronized`)
就像给厕所加了一把锁，进去一个人锁上门，出来才开门。

```java
Object lock = new Object(); // 锁对象（必须是唯一的）

synchronized (lock) {
    // 操作共享数据的代码
    if (ticket > 0) {
        try { Thread.sleep(10); } catch (Exception e) {} // 模拟延时
        System.out.println("卖出第 " + ticket-- + " 张票");
    }
}
```

#### 方法 B：同步方法
直接在方法声明上加关键字。

```java
public synchronized void sellTicket() {
    if (ticket > 0) {
        System.out.println("卖出: " + ticket--);
    }
}
```

#### 方法 C：Lock 锁 (JDK 5+ 新特性)
比 `synchronized` 更灵活，必须手动上锁和释放锁。

```java
// 1. 定义锁对象
Lock lock = new ReentrantLock();

// 2. 使用
lock.lock(); // 上锁
try {
    // 业务代码
} finally {
    lock.unlock(); // 必须在 finally 中解锁，防止死锁
}
```

## 5. 线程池 (Thread Pool) —— 工作必用
> 为什么需要线程池？
> 每当有一个任务就 `new Thread()` 非常消耗系统资源（创建和销毁都需要时间）。线程池就像共享单车，用完不销毁，放回池子里给下一个人用。

### 如何创建
Java 提供了 `Executors` 工具类（但在大厂开发规范中，建议手动创建 `ThreadPoolExecutor`，初学者先了解工具类即可）。

```java
// 创建一个固定大小为 5 的线程池
ExecutorService pool = Executors.newFixedThreadPool(5);

// 提交任务
Runnable task = () -> System.out.println("我是线程池中的线程");
pool.submit(task);
pool.submit(task);

// 关闭线程池（通常项目中不关闭）
pool.shutdown();
```

## 6. 常见面试题与坑 (Checklist)

1.  `start()` 和 `run()` 的区别？
    *   `run()` 只是普通方法调用，还是在主线程跑。
    *   `start()` 才是启动新线程。
2.  `sleep()` 和 `wait()` 的区别？
    *   `sleep()`: 我睡一会，但我抱着锁睡（不释放锁）。来自于 `Thread` 类。
    *   `wait()`: 我等一会，我交出锁（释放锁），让别人先用。来自于 `Object` 类。
3.  什么是死锁 (Deadlock)？
    *   线程 A 拿着锁 1 想要锁 2，线程 B 拿着锁 2 想要锁 1，互相僵持。
