
# 3. 方法 (Method)

核心目标：
1. 理解为什么要用方法（代码复用）。
2. 掌握方法的定义与调用格式。
3. 理解 形参 与 实参。
4. 重点：掌握方法重载 (Overloading)。

---

## 1. 什么是方法？为什么需要它？

### 场景模拟
假设你要写一个程序，需要多次计算两个数字的和。
如果不使用方法，你可能需要在代码的不同地方重复写 `int sum = a + b;`。
如果逻辑变得复杂（比如：计算和之后还要判断是否为偶数），重复代码会非常多，且难以维护。

方法的优点：
*   代码复用：写一次，到处用。
*   模块化：把复杂的逻辑拆分成小的功能块，代码更清晰。

## 2. 方法的定义格式

初学者在练习阶段，通常将方法定义为 `public static`，这样可以在 `main` 方法中直接调用。

### 语法结构
```java
修饰符 返回值类型 方法名(参数类型 参数名1, 参数类型 参数名2, ...) {
    // 方法体（代码逻辑）
    return 返回值;
}
```

### 组成部分解析
1.  修饰符：目前固定写 `public static`（后续面向对象阶段会详解）。
2.  返回值类型：
    *   如果方法执行完需要给调用者一个结果（如计算求和），写具体类型（`int`, `double`, `String` 等）。
    *   如果方法只是执行一个动作（如打印一行字），不需要给结果，写 `void`。
3.  方法名：遵循“小驼峰命名法”，动词开头，如 `add`, `getUserName`, `checkLogin`。
4.  参数列表：进入方法的“原材料”。可以没有参数，也可以有多个。
5.  return：结束方法，并将结果返回。如果类型是 `void`，可以不写 `return`，或者只写 `return;`。

## 3. 方法的定义与调用示例

### 示例 1：无返回值，无参数
```java
public class MethodDemo {
    public static void main(String[] args) {
        // 调用方法
        printWelcome(); 
        printWelcome(); // 可以重复调用
    }

    // 定义一个打印欢迎信息的方法
    public static void printWelcome() {
        System.out.println("-------------------");
        System.out.println("欢迎来到 Java 世界！");
        System.out.println("-------------------");
    }
}
```

### 示例 2：有返回值，有参数
```java
public class MethodDemo {
    public static void main(String[] args) {
        // 调用方法，并接收返回值
        int result = add(10, 20); 
        System.out.println("和是：" + result);

        // 也可以直接打印调用结果
        System.out.println("5 + 8 = " + add(5, 8));
    }

    // 定义一个求和方法
    // int a, int b 是形式参数（形参）
    public static int add(int a, int b) {
        int sum = a + b;
        return sum; // 返回结果，必须与方法定义的 int 类型一致
    }
}
```

## 4. ⚠️ 必须要懂的概念：形参 vs 实参

*   形参 (Formal Parameter)：定义方法时声明的变量。
    *   例如上面 `add(int a, int b)` 中的 `a` 和 `b`。它们只是占位符。
*   实参 (Actual Parameter)：调用方法时实际传入的值。
    *   例如 `add(10, 20)` 中的 `10` 和 `20`。

> 初学者深坑警告：
> Java 中的参数传递是 值传递 (Pass By Value)。
> 对于基本数据类型（int, double 等），方法内部修改形参的值，不会 影响方法外部的实参。

```java
public static void main(String[] args) {
    int x = 10;
    change(x);
    System.out.println(x); // 输出仍然是 10，而不是 20！
}

public static void change(int num) {
    num = 20; // 这里只改了方法内部 num 的值，不影响外面的 x
}
```

## 5. 方法重载 (Method Overloading)

同一个类中，方法名相同，但参数列表不同，称为方法重载。

为什么需要重载？
比如 `System.out.println()`，它可以打印数字，也可以打印字符串，还可以打印布尔值。如果不支持重载，你可能需要记 `printlnInt()`, `printlnString()`, `printlnBool()`，非常麻烦。

### 重载的规则（口诀：两同、一不同）
*   两同：在同一个类中，方法名相同。
*   一不同：参数列表不同（个数不同，或者类型不同，或者顺序不同）。
*   无关：与返回值类型无关，与参数变量名无关。

```java
public class OverloadDemo {
    public static void main(String[] args) {
        System.out.println(sum(10, 20));      // 自动调用两个整数的
        System.out.println(sum(10.5, 20.5));  // 自动调用两个小数的
        System.out.println(sum(10, 20, 30));  // 自动调用三个整数的
    }

    // 1. 两个整数相加
    public static int sum(int a, int b) {
        return a + b;
    }

    // 2. 两个小数相加（参数类型不同）
    public static double sum(double a, double b) {
        return a + b;
    }

    // 3. 三个整数相加（参数个数不同）
    public static int sum(int a, int b, int c) {
        return a + b + c;
    }
}
```

## 6. 初学者常见错误 (Bug 排查)

1.  方法不能嵌套定义：
    *   ❌ 错误：在 `main` 方法里面定义 `add` 方法。
    *   ✅ 正确：`main` 方法和 `add` 方法是平级关系，都定义在类 (`class`) 里面。

2.  返回值类型不匹配：
    *   定义了 `public static int`，最后却 `return "hello";` 或者忘记写 `return`。

3.  调用参数不匹配：
    *   方法需要传 2 个 `int`，你传了 1 个 `String`。
