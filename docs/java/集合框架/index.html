8. Java 集合框架

1. 为什么需要集合？​

在学习数组时，我们知道数组有一个巨大的缺点：长度固定。 一旦定义了 String[] arr = new String[10];，它就只能装10个，装第11个就会报错。

集合 (Collection) 的出现就是为了解决这个问题：

  • 动态扩容：可以根据需要自动增加容量。
  • 丰富的操作：自带增删改查、排序、去重等方法。
  • 多种结构：提供了链表、哈希表、树等多种数据结构的实现。

2. 集合框架体系图 (这是地图)​

Java 集合主要分为两大派系：

  1. Collection 接口：单列集合，存放一个个对象（如：[A, B, C]）。
  2. Map 接口：双列集合，存放键值对（Key-Value）（如：{name=张三, age=18}）。

3. List 接口 (有序、可重复)​

List 就像一个可以自动扩容的数组。它保证元素的存入顺序，并且允许存放重复元素。

3.1 ArrayList (最常用)​

  • 底层实现：数组。
  • 特点：
    • 查询快：通过索引（下标）直接访问。
    • 增删慢：插入或删除元素时，需要移动后面的所有元素。
  • 场景：读多写少（绝大多数业务场景）。

3.2 LinkedList​

  • 底层实现：双向链表。
  • 特点：
    • 查询慢：需要从头或尾一个一个找。
    • 增删快：只需要修改前后节点的指向。

✅ 代码示例：ArrayList 的使用​

import java.util.ArrayList;
import java.util.List; // 推荐使用接口作为引用类型

public class ListDemo {
    public static void main(String[] args) {
        // 1. 创建集合 (使用泛型 <String> 约束只能存字符串)
        // 这里的 new ArrayList<>() 后面尖括号可以不写类型，自动推断
        List<String> list = new ArrayList<>();

        // 2. 添加元素
        list.add("Java");
        list.add("Python");
        list.add("Java"); // 允许重复

        // 3. 插入元素
        list.add(1, "C++"); // 在索引1的位置插入

        // 4. 获取元素
        String s = list.get(0); 
        System.out.println("第一个元素: " + s);

        // 5. 删除元素
        list.remove("Python"); // 按内容删
        // list.remove(0);     // 按索引删

        // 6. 获取长度
        System.out.println("集合大小: " + list.size());
        
        // 7. 打印
        System.out.println(list); // [Java, C++, Java]
    }
}

4. Set 接口 (无序、不可重复)​

Set 主要用于去重。它不保证存入的顺序（你存入 A, B, C，取出来可能是 C, A, B）。

4.1 HashSet (最常用)​

  • 底层实现：哈希表（实际上是 HashMap 的 Key）。
  • 特点：速度极快，无序，自动去重。
  • 注意：如果要存自定义对象（如 Student），必须重写 hashCode() 和 equals() 方法，否则去重失效。

4.2 TreeSet​

  • 底层实现：红黑树。
  • 特点：会对元素进行自动排序。

✅ 代码示例：HashSet 去重​

import java.util.HashSet;
import java.util.Set;

public class SetDemo {
    public static void main(String[] args) {
        Set<Integer> set = new HashSet<>();
        
        set.add(10);
        set.add(20);
        set.add(10); // 这个加不进去，因为重复了
        set.add(5);

        // 输出顺序是不确定的，且没有重复元素
        System.out.println(set); // 可能输出: [20, 5, 10]
        
        // Set 没有 get(i) 方法！因为它是无序的，没有索引概念。
    }
}

5. Map 接口 (键值对 Key-Value)​

Map 是独立于 Collection 的另一个接口，用于处理映射关系。 例如：学号 -> 学生信息，身份证号 -> 人。

5.1 HashMap (核心)​

  • 底层实现：数组 + 链表 + 红黑树 (JDK 8+)。
  • 特点：
    • Key 不允许重复，Value 可以重复。
    • Key 允许为 null。
    • 无序。

5.2 TreeMap​

  • 特点：按照 Key 进行排序。

✅ 代码示例：HashMap 操作​

import java.util.HashMap;
import java.util.Map;

public class MapDemo {
    public static void main(String[] args) {
        // Key是String, Value是Integer
        Map<String, Integer> scores = new HashMap<>();

        // 1. 添加/修改 (put)
        scores.put("Alice", 90);
        scores.put("Bob", 85);
        scores.put("Alice", 100); // Key重复，会覆盖旧值 (90 -> 100)

        // 2. 获取 (get)
        Integer s = scores.get("Alice");
        System.out.println("Alice的分数: " + s); // 100

        // 3. 判断是否存在
        boolean hasBob = scores.containsKey("Bob");

        // 4. 删除
        scores.remove("Bob");
        
        // 5. 遍历 Map (重点)
        // 方式一：遍历 Key
        for (String key : scores.keySet()) {
            System.out.println(key + " : " + scores.get(key));
        }
    }
}

6. 集合的遍历方式​

除了普通的 for(int i=0; ...) 循环（仅 List 可用），必须掌握以下两种：

6.1 增强 for 循环 (Foreach) —— 推荐​

语法简洁，适用于所有 Collection 和 数组。

List<String> list = Arrays.asList("A", "B", "C");

for (String s : list) {
    System.out.println(s);
}

6.2 迭代器 (Iterator) —— 原理​

如果在遍历过程中需要删除元素，必须使用迭代器，否则会报 ConcurrentModificationException 异常。

Iterator<String> it = list.iterator();
while(it.hasNext()) {
    String s = it.next();
    if("B".equals(s)) {
        it.remove(); // 安全删除
    }
}

7. 常见面试题 (提前演练)​

  1. Array 和 ArrayList 的区别？
    • Array 长度固定，可以存基本类型和对象。
    • ArrayList 长度动态，只能存对象（基本类型要用包装类），功能更强。
  2. ArrayList 和 LinkedList 的区别？
    • ArrayList 基于数组，查快增删慢。
    • LinkedList 基于链表，查慢增删快。
  3. HashMap 的底层原理是什么？(高频)
    • 简单回答：数组 + 链表 + (JDK8以后) 红黑树。当链表长度超过8时，自动转为红黑树以提高查询效率。
