## 1. 基础概念与环境准备

### 什么是 MySQL？
MySQL 是目前最流行的开源关系型数据库。
*   数据库 (Database): 相当于一个文件夹。
*   表 (Table): 相当于一个 Excel 文件。
*   行 (Row): 一条具体的数据（如：张三的信息）。
*   列 (Column): 数据的属性（如：姓名、年龄、电话）。

### 🛠️ 工具安装 (必做)
不要只用黑窗口（命令行）敲代码，效率太低。
1.  服务端: 安装 MySQL Community Server (建议 5.7 或 8.0 版本)。
2.  客户端 (GUI工具): 推荐安装 Navicat (收费/破解) 或 DBeaver (开源免费，强烈推荐) 或 DataGrip (JetBrains全家桶，好用但收费)。

## 2. SQL 语言分类
SQL (Structured Query Language) 是操作数据库的标准语言。主要分为四类，Java 开发最常用的是前三类：

1.  DDL (Data Definition): 定义库、表结构 (`CREATE`, `DROP`, `ALTER`)。
2.  DML (Data Manipulation): 增删改数据 (`INSERT`, `DELETE`, `UPDATE`)。
3.  DQL (Data Query): 查询数据 (`SELECT`) —— 最核心、最难。
4.  DCL (Data Control): 权限控制 (用户管理，运维关注较多)。

## 3. 实战操作：DDL (建表)

假设我们要开发一个“学生管理系统”，我们需要一张学生表。

```sql
-- 1. 创建数据库
CREATE DATABASE IF NOT EXISTS school_db CHARACTER SET utf8mb4;

-- 2. 使用数据库
USE school_db;

-- 3. 创建学生表 (注意数据类型和约束)
CREATE TABLE student (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    username VARCHAR(50) NOT NULL COMMENT '姓名',
    gender TINYINT DEFAULT 1 COMMENT '性别 1:男 2:女',
    age INT COMMENT '年龄',
    score DOUBLE(5,2) COMMENT '分数',
    enroll_date DATE COMMENT '入学日期'
) COMMENT '学生信息表';
```

> 💡 关键点：
> *   `PRIMARY KEY`: 主键，每行数据的唯一标识，不可重复。
> *   `AUTO_INCREMENT`: 自动增长，不需要手动填 ID，数据库会自动生成 1, 2, 3...
> *   `VARCHAR`: 可变长度字符串，比 `CHAR` 省空间。
> *   `utf8mb4`: 支持 Emoji 表情的编码格式。

## 4. 实战操作：DML (增删改)

### 插入数据 (INSERT)
```sql
-- 插入单条数据
INSERT INTO student (username, gender, age, score, enroll_date) 
VALUES ('张三', 1, 20, 88.5, '2023-09-01');

-- 插入多条数据
INSERT INTO student (username, gender, age, score, enroll_date) 
VALUES 
('李四', 2, 19, 92.0, '2023-09-01'),
('王五', 1, 22, 75.5, '2022-09-01'),
('赵六', 2, 21, 60.0, '2022-09-01');
```

### 修改数据 (UPDATE)
> ⚠️ 警告：执行 UPDATE 时一定要加 `WHERE` 条件，否则会修改整张表！

```sql
-- 把 '张三' 的分数改为 95
UPDATE student SET score = 95 WHERE username = '张三';

-- 把所有人的年龄加 1 (慎用)
-- UPDATE student SET age = age + 1;
```

### 删除数据 (DELETE)
> ⚠️ 警告：同样必须加 `WHERE`，否则清空整张表！

```sql
-- 删除 ID 为 3 的学生
DELETE FROM student WHERE id = 3;
```

## 5. 实战操作：DQL (查询) —— 核心中的核心

Java 后端开发 80% 的时间都在写查询。

### 基础查询
```sql
-- 查询所有列 (生产环境尽量少用 SELECT *)
SELECT * FROM student;

-- 查询指定列 (推荐)
SELECT username, score FROM student;

-- 去除重复值
SELECT DISTINCT gender FROM student;
```

### 条件查询 (WHERE)
```sql
-- 逻辑运算符: AND, OR, NOT
SELECT * FROM student WHERE age > 20 AND score >= 60;

-- 范围查询: BETWEEN ... AND ...
SELECT * FROM student WHERE score BETWEEN 80 AND 100;

-- 模糊查询 (LIKE): % 代表任意字符
-- 查询姓 '张' 的人
SELECT * FROM student WHERE username LIKE '张%';
-- 查询名字里带 '三' 的人
SELECT * FROM student WHERE username LIKE '%三%';
```

### 排序 (ORDER BY)
```sql
-- 按分数从高到低排序 (DESC: 降序, ASC: 升序)
SELECT * FROM student ORDER BY score DESC;

-- 组合排序: 先按年龄升序，年龄相同按分数降序
SELECT * FROM student ORDER BY age ASC, score DESC;
```

### 分页查询 (LIMIT) —— Web 开发必备
用户界面一页只显示 10 条数据。
```sql
-- 语法: LIMIT 起始索引, 查询条数
-- 查询前 3 名
SELECT * FROM student ORDER BY score DESC LIMIT 0, 3;

-- 查询第 2 页数据 (假设每页 2 条)
-- 公式: LIMIT (page - 1) * pageSize, pageSize
SELECT * FROM student LIMIT 2, 2;
```

## 6. 进阶查询：聚合与分组

### 聚合函数
用于统计数据，结果通常只有一行。
*   `COUNT(*)`: 统计总记录数。
*   `SUM(score)`: 求和。
*   `AVG(score)`: 平均值。
*   `MAX(score)` / `MIN(score)`: 最大/最小值。

```sql
-- 统计班级总人数
SELECT COUNT(*) FROM student;

-- 统计所有学生的平均分
SELECT AVG(score) FROM student;
```

### 分组查询 (GROUP BY)
```sql
-- 统计男生和女生各有多少人
SELECT gender, COUNT(*) FROM student GROUP BY gender;

-- 统计男生女生的平均分
SELECT gender, AVG(score) FROM student GROUP BY gender;
```

> Having 子句: 对分组后的结果再进行过滤。
> *   例如：查询平均分大于 80 分的性别组。
>   ```sql
>   SELECT gender, AVG(score) FROM student GROUP BY gender HAVING AVG(score) > 80;
>   ```

## 7. 多表查询 (Join) —— 难点

实际项目中，数据是分散在不同表里的。例如：学生表 (`student`) 和 班级表 (`class`)。

假设场景:
*   `student` 表有一个列 `class_id`。
*   `class` 表有 `id` 和 `class_name`。

### 1. 内连接 (INNER JOIN)
只查询两个表都有的数据（交集）。
```sql
-- 查询学生姓名和对应的班级名称
SELECT s.username, c.class_name
FROM student s
INNER JOIN class c ON s.class_id = c.id;
```

### 2. 左外连接 (LEFT JOIN) —— 最常用
以左表为主，左表数据全显示，右表没有的显示 NULL。
```sql
-- 查询所有学生以及他们的班级（即使有的学生还没有分配班级，也要显示学生）
SELECT s.username, c.class_name
FROM student s
LEFT JOIN class c ON s.class_id = c.id;
```

## 8. 必须理解的概念：事务 (Transaction)

比如银行转账：A 转给 B 100元。
1. A 的余额 - 100。
2. (如果这里断电了怎么办？)
3. B 的余额 + 100。

事务保证这组操作要么全部成功，要么全部失败（回滚）。

```sql
START TRANSACTION; -- 开启事务

UPDATE account SET money = money - 100 WHERE name = 'A';
UPDATE account SET money = money + 100 WHERE name = 'B';

COMMIT; -- 提交事务 (生效)
-- ROLLBACK; -- 回滚事务 (撤销操作)
```

ACID 四大特性 (面试必背):
1.  A (Atomicity) 原子性: 同生共死，不可分割。
2.  C (Consistency) 一致性: 事务前后数据总量守恒。
3.  I (Isolation) 隔离性: 多个事务互不干扰。
4.  D (Durability) 持久性: 提交后永久保存。
