

# 10. IO 流与文件操作

学习目标：
1. 理解“流 (Stream)”的概念。
2. 掌握文件 (`File`) 的基本操作。
3. 能够使用代码读取和写入文件（文本文件与二进制文件）。
4. 重点：掌握 `try-with-resources` 语法，防止资源泄露。

---

## 1. 核心概念：什么是“流”？

想象一根水管：
*   数据 就是水。
*   文件/网络/内存 是水源或蓄水池。
*   IO 流 就是连接程序和水源的水管。

### 流的分类体系 (一张表看懂)

Java 的 IO 流主要在 `java.io` 包下，看似类很多，其实主要就分为四大派系：

| 维度 | 分类 | 说明 | 顶级父类 (抽象类) |
| :--- | :--- | :--- | :--- |
| 按数据单位 | 字节流 (Byte) | 万能流。操作 8 位字节。适合图片、视频、音频、PDF 等所有文件。 | `InputStream`, `OutputStream` |
| | 字符流 (Character) | 文本专用。操作字符。适合 `.txt`, `.java`, `.json` 等人类可读文本。 | `Reader`, `Writer` |
| 按功能 | 节点流 | 直接连在文件上的“管子”。 | `FileInputStream`, `FileReader` |
| | 处理流 (包装流) | 套在节点流外面的“粗管子”，增加功能（如缓冲）。 | `BufferedInputStream`, `BufferedReader` |

> ⭐ 记忆口诀：
> *   类名以 `Stream` 结尾的都是字节流。
> *   类名以 `Reader/Writer` 结尾的都是字符流。

## 2. 文件的抽象：File 类

在读写内容之前，你需要先能找到文件。`java.io.File` 类代表文件或目录的路径名。

### 常用操作
```java
import java.io.File;
import java.io.IOException;

public class FileDemo {
    public static void main(String[] args) throws IOException {
        // 1. 创建 File 对象 (注意：这只是一个内存对象，硬盘上可能还没有这个文件)
        // 建议使用绝对路径，或者理解相对路径是相对于项目根目录
        File file = new File("demo.txt"); 

        // 2. 判断是否存在
        if (file.exists()) {
            System.out.println("文件已存在");
            System.out.println("文件大小: " + file.length() + " 字节");
            System.out.println("绝对路径: " + file.getAbsolutePath());
        } else {
            // 3. 创建新文件
            boolean created = file.createNewFile();
            System.out.println("文件创建成功: " + created);
        }
        
        // 4. 判断是文件还是文件夹
        System.out.println("是文件吗? " + file.isFile());
        System.out.println("是目录吗? " + file.isDirectory());
        
        // 5. 删除文件
        // file.delete(); 
    }
}
```

## 3. 必会写法：try-with-resources (自动关闭流)

⚠️ 严重警告：所有的 IO 流使用完毕后必须关闭 (`close()`)，否则会占用系统资源，导致内存泄露或文件无法删除。

在 Java 7 之前，我们需要在 `finally` 块中痛苦地关闭流。现在，请直接背诵并使用 Java 7+ 的 `try-with-resources` 语法：

```java
// 语法结构：try (在这里创建流对象) { ... }
// 只要代码出了 try 的大括号，流会自动关闭，无需手动写 close()
try (FileInputStream fis = new FileInputStream("input.txt")) {
    // 读写操作
} catch (IOException e) {
    e.printStackTrace();
}
```

## 4. 实战一：字节流 (复制图片)

字节流是万能的。我们尝试将一张图片从 `src.jpg` 复制到 `dest.jpg`。

涉及类：`FileInputStream` (输入), `FileOutputStream` (输出)

```java
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class CopyImage {
    public static void main(String[] args) {
        // 定义源文件和目标文件路径
        String srcPath = "C:/Images/logo.png";
        String destPath = "C:/Images/logo_copy.png";

        // try-with-resources 自动关闭资源
        try (
            FileInputStream fis = new FileInputStream(srcPath);
            FileOutputStream fos = new FileOutputStream(destPath)
        ) {
            // 定义一个缓冲数组（一次搬运 1024 个字节，即 1KB）
            // 如果一个字节一个字节读，效率极低，像用吸管喝水；用数组像用桶倒水。
            byte[] buffer = new byte[1024]; 
            int len; // 记录每次实际读取到的字节数

            // 循环读取：read(buffer) 会把数据填入数组，返回读取的长度，读到末尾返回 -1
            while ((len = fis.read(buffer)) != -1) {
                // 写入：从 buffer 数组中写，从 0 开始，写 len 这么长
                fos.write(buffer, 0, len);
            }
            System.out.println("图片复制完成！");

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 5. 实战二：字符流 (读写文本)

如果你要处理中文文本，字节流容易出现乱码（因为一个汉字可能占 3 个字节，切断了就乱了）。这时候用字符流。

涉及类：`FileReader`, `FileWriter`

```java
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;

public class TextDemo {
    public static void main(String[] args) {
        // 1. 写入文本
        try (FileWriter fw = new FileWriter("note.txt", true)) { // true 表示追加模式，不覆盖原内容
            fw.write("Hello Java IO! \n");
            fw.write("你好，世界！"); // 直接写字符串，不用转字节
        } catch (IOException e) {
            e.printStackTrace();
        }

        // 2. 读取文本
        try (FileReader fr = new FileReader("note.txt")) {
            int data;
            // 这是一个字符一个字符的读，效率一般，但逻辑简单
            while ((data = fr.read()) != -1) {
                System.out.print((char) data); // 强转为 char 显示
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 6. 进阶：缓冲流 (高效 IO)

普通的文件流是直接读写硬盘，速度慢。缓冲流（Buffered）会在内存中创建一个缓冲区（默认 8KB），尽量减少读写硬盘的次数。

推荐做法：以后写代码，尽量在节点流外面包一层缓冲流。

*   `FileInputStream` -> `BufferedInputStream`
*   `FileReader` -> `BufferedReader` (拥有特技：`readLine()` 一次读一行)

```java
import java.io.*;

public class BufferedReaderDemo {
    public static void main(String[] args) {
        try (
            FileReader fr = new FileReader("note.txt");
            BufferedReader br = new BufferedReader(fr) // 包装起来
        ) {
            String line;
            // readLine() 是处理文本的神技，一次读一行，读不到返回 null
            while ((line = br.readLine()) != null) {
                System.out.println("读取一行：" + line);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 7. 现代化 IO：Java NIO (Files 工具类)

Java 7 引入了 `java.nio.file.Files`，它提供了极其方便的静态方法，适合小文件的快速读写，代码量极少。在现代开发中，如果文件不大，优先用这个。

```java
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.List;

public class NioDemo {
    public static void main(String[] args) throws Exception {
        Path path = Paths.get("note.txt");

        // 1. 一行代码读取所有内容 (Java 11+)
        String content = Files.readString(path);
        System.out.println(content);

        // 2. 读取所有行到一个 List 中
        List<String> lines = Files.readAllLines(path);
        
        // 3. 一行代码写入内容
        Files.writeString(path, "这是新写入的内容");
    }
}
```

## 8. 特殊流：对象流与序列化 (Serialization)

有时候我们需要把整个 Java 对象（比如一个 `User` 对象，包含姓名、年龄、密码）直接存到文件里，或者通过网络传给别人。这就需要序列化。

*   序列化 (Serialization): 把对象转换为字节序列的过程（保存）。
*   反序列化 (Deserialization): 把字节序列恢复为对象的过程（读取）。

核心要求：要序列化的类必须实现 `java.io.Serializable` 接口（这是一个标记接口，里面没有任何方法，但不加会报错）。

```java
import java.io.*;

// 1. 必须实现 Serializable 接口
class User implements Serializable {
    private static final long serialVersionUID = 1L; // 建议加上版本号，防止类修改后读取报错
    String name;
    int age;
    // transient 关键字修饰的字段不会被序列化（比如密码不想存进文件）
    transient String password; 

    public User(String name, int age, String password) {
        this.name = name;
        this.age = age;
        this.password = password;
    }
}

public class ObjectStreamDemo {
    public static void main(String[] args) {
        String filePath = "user.dat"; // 后缀名随意

        // 2. 序列化：写入对象
        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream(filePath))) {
            User user = new User("Alice", 25, "123456");
            oos.writeObject(user);
            System.out.println("对象保存成功！");
        } catch (IOException e) {
            e.printStackTrace();
        }

        // 3. 反序列化：读取对象
        try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream(filePath))) {
            User user = (User) ois.readObject(); // 强转回来
            System.out.println("读取对象: " + user.name + ", " + user.age);
            System.out.println("密码: " + user.password); // 输出 null，因为加了 transient
        } catch (IOException | ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}
```

## 📝 学习重点 (Summary)

整理一下 IO 阶段必须死记硬背的重点：

1.  流的选择：
    *   操作文本文件（txt, xml, json, java） -> 用 字符流 (`FileReader/Writer`, `BufferedReader/Writer`)。
    *   操作非文本文件（图片, 视频, 音频, pdf） -> 必须用 字节流 (`FileInputStream/OutputStream`)。
    *   不知道文件类型 -> 盲选 字节流（它是万能的）。
2.  效率原则：
    *   永远优先使用 缓冲流 (`Buffered...`)，或者创建一个大的 `byte[]` 数组作为缓冲区，不要一个字节一个字节地读写。
3.  资源关闭：
    *   永远使用 `try-with-resources` 语法，忘记 `close()` 是新人最大的 Bug 来源。
4.  乱码问题：
    *   乱码通常是因为 编码不一致（比如写入用 UTF-8，读取用 GBK）。
    *   现代开发统一且强制使用 UTF-8。

## ⚠️ 常见坑点 (Pitfalls)

1.  相对路径问题：
    *   写代码时写 `new File("a.txt")`，文件到底在哪？
    *   在 IDEA 中，默认是在 项目的根目录 下（和 `src` 同级），而不是在 `src` 里面。
2.  文件分隔符：
    *   Windows 用反斜杠 `\`，Mac/Linux 用斜杠 `/`。
    *   代码中建议使用 `File.separator` 或者直接用 `/` (Java 在 Windows 下也能识别 `/`)，千万不要把路径写死成 `C:\\Users\\...`，这样代码换个电脑就跑不起来了。
3.  flush() 与 close()：
    *   `Writer` (字符输出流) 有缓冲区。如果你写了数据但没有调用 `flush()` 或 `close()`，数据可能还在内存里，没存到硬盘上（丢数据）。`close()` 会自动调用一次 `flush()`。
