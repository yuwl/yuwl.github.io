# 1. Kafka 基础入门

## 什么是 Kafka？

Apache Kafka 是一个分布式流处理平台，最初由 LinkedIn 开发，后来捐赠给了 Apache 基金会。它主要用于构建实时数据管道和流式应用程序。

### 核心特性
- **高吞吐量**：即使在廉价的商用机器上，也能每秒处理数百万条消息。
- **持久化**：消息被持久化到磁盘，并支持副本机制以防止数据丢失。
- **分布式**：天然支持水平扩展。
- **实时性**：延迟极低，适用于实时数据分析。

## 环境安装与启动

在开始之前，确保你的机器上已安装 **Java 8+**。

### 1. 下载 Kafka
从 [Apache Kafka 官网](https://kafka.apache.org/downloads) 下载最新的二进制安装包并解压。

> **Windows 用户提示**：Kafka 官方包包含 Windows 脚本（位于 `bin\windows` 目录下）。建议将 Kafka 解压到简短的路径（如 `C:\kafka`），以避免路径过长导致的报错。

```bash
# Linux/macOS 下载示例
wget https://downloads.apache.org/kafka/3.5.0/kafka_2.13-3.5.0.tgz
tar -xzf kafka_2.13-3.5.0.tgz
cd kafka_2.13-3.5.0
```

### 2. 启动环境 (ZooKeeper 模式)
Kafka 依赖 ZooKeeper，首先启动 ZooKeeper 服务：

**Linux/macOS:**
```bash
bin/zookeeper-server-start.sh config/zookeeper.properties
```

**Windows:**
```powershell
.\bin\windows\zookeeper-server-start.bat .\config\zookeeper.properties
```

打开另一个终端，启动 Kafka Broker：

**Linux/macOS:**
```bash
bin/kafka-server-start.sh config/server.properties
```

**Windows:**
```powershell
.\bin\windows\kafka-server-start.bat .\config\server.properties
```

## 核心概念

1.  **Producer (生产者)**：负责发布消息到 Kafka Topic。
2.  **Consumer (消费者)**：订阅 Topic 并处理消息。
3.  **Broker (服务代理)**：Kafka 集群中的一台服务器。
4.  **Topic (主题)**：消息的逻辑分类。
5.  **Partition (分区)**：Topic 的物理切分，实现并发处理。

## 快速生成与消费示例

使用命令行工具进行简单测试：

```bash
# 创建主题
bin/kafka-topics.sh --create --topic test --bootstrap-server localhost:9092

# 发送消息（输入后按回车发送，Ctrl+C 退出）
bin/kafka-console-producer.sh --topic test --bootstrap-server localhost:9092
> hello kafka
> learning docusaurus

# 消费消息（会看到刚才发送的消息）
bin/kafka-console-consumer.sh --topic test --from-beginning --bootstrap-server localhost:9092
hello kafka
learning docusaurus
```

## 常用命令行汇总

### Topic 管理
```bash
# 查看所有 Topic
bin/kafka-topics.sh --list --bootstrap-server localhost:9092

# 查看特定 Topic 详情
bin/kafka-topics.sh --describe --topic test --bootstrap-server localhost:9092

# 修改 Topic (例如增加分区)
bin/kafka-topics.sh --alter --topic test --partitions 3 --bootstrap-server localhost:9092

# 删除 Topic
bin/kafka-topics.sh --delete --topic test --bootstrap-server localhost:9092
```

### 消费者组管理
```bash
# 查看所有消费者组
bin/kafka-consumer-groups.sh --list --bootstrap-server localhost:9092

# 查看消费者组状态（消费进度/堆积量）
bin/kafka-consumer-groups.sh --describe --group my-group --bootstrap-server localhost:9092

# 重置 Offset (移动到最早位置)
bin/kafka-consumer-groups.sh --group my-group --topic test --reset-offsets --to-earliest --execute --bootstrap-server localhost:9092
```
