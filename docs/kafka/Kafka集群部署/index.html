3. Kafka 集群部署与实践

环境准备​

  • Java 8+
  • ZooKeeper (Kafka 3.0 之前版本必需，KRaft 模式在 3.0+ 可选)

常用配置 (server.properties)​

配置项说明
broker.id集群中唯一个标识
listeners监听地址
log.dirs日志存储路径
zookeeper.connectZK 连接地址
num.partitions默认分区数

KRaft 模式 (新特性)​

Kafka 3.0 引入了 KRaft 模式，移除了对 ZooKeeper 的依赖。

  • 控制器不再依赖 ZK 进行元数据管理。
  • 提高了元数据更新的效率和集群的稳定性。

监控与维护​

常用指标​

  • Messages in per Sec：每秒入站消息数。
  • Bytes out per Sec：每秒出站字节数。
  • Consumer Lag：消费者堆积量（最关键的监控指标）。

性能调优建议​

  • 增加分区数以提高并发。
  • 调整 batch.size 和 linger.ms 以提高吞吐。
  • 确保磁盘 IO 性能。
