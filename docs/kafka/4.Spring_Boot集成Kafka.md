# 4. Spring Boot 集成 Kafka

## 1. 引入依赖

在 `pom.xml` 中引入 Spring Kafka 开发包：

```xml
<dependency>
    <groupId>org.springframework.kafka</groupId>
    <artifactId>spring-kafka</artifactId>
</dependency>
```

## 2. 配置文件 (application.yml)

```yaml
spring:
  kafka:
    bootstrap-servers: localhost:9092
    producer:
      key-serializer: org.apache.kafka.common.serialization.StringSerializer
      value-serializer: org.apache.kafka.common.serialization.StringSerializer
      # 生产者重试次数
      retries: 3
    consumer:
      group-id: my-boot-group
      auto-offset-reset: earliest
      key-deserializer: org.apache.kafka.common.serialization.StringDeserializer
      value-deserializer: org.apache.kafka.common.serialization.StringDeserializer
```

## 3. 生产者代码示例

使用 `KafkaTemplate` 发送消息：

```java
@RestController
public class KafkaProducerController {

    @Autowired
    private KafkaTemplate<String, String> kafkaTemplate;

    @GetMapping("/send")
    public String send(String message) {
        kafkaTemplate.send("test-topic", message);
        return "Message sent: " + message;
    }
}
```

## 4. 消费者代码示例

使用 `@KafkaListener` 注解监听主题：

```java
@Component
public class KafkaConsumer {

    @KafkaListener(topics = "test-topic", groupId = "my-boot-group")
    public void listen(String message) {
        System.out.println("Received message in group my-boot-group: " + message);
    }
}
```

## 5. 进阶配置

### 批量消费
在配置中开启批量消费模式：
```yaml
spring:
  kafka:
    listener:
      type: batch
```
代码中接收 `List`:
```java
@KafkaListener(topics = "test-topic")
public void listenBatch(List<String> messages) {
    System.out.println("Batch received: " + messages.size());
}
```
