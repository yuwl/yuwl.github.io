# 2. Kafka 核心概念详解

## Topic 与 Partition

### Topic (主题)
Topic 是 Kafka 中数据的分类单位。生产者将消息发送到特定的 Topic，消费者从特定的 Topic 读取数据。

### Partition (分区)
一个 Topic 可以包含多个 Partition。
- **有序性**：Partition 内部的消息是有序的（通过 Offset 标识）。
- **并行处理**：Partition 是 Kafka 提高并行度的一种手段。不同的 Partition 可以分布在不同的 Broker 上。

## Producer 写入策略

1.  **轮询 (Round-robin)**：默认策略，均匀分配到各个分区。
2.  **按 Key 分区**：具有相同 Key 的消息会被发送到同一个分区。
3.  **自定义分区器**：根据业务逻辑决定消息去向。

## Consumer Group (消费者组)

- 每个消费者属于一个消费者组。
- 一个 Partition 只能被同一个消费者组内的一个消费者消费。
- 这种机制实现了 **发布/订阅** 和 **负载均衡** 两种模型。

## 副本机制 (Replication)

Kafka 通过副本机制实现高可用性。
- **Leader**：负责所有的读写请求。
- **Follower**：同步 Leader 的数据，不处理读写请求。
- **ISR (In-Sync Replicas)**：与 Leader 保持同步的副本列表。
