# 2. Redis 核心数据结构

Redis 提供了多种数据结构来满足不同的业务场景。

## 1. String (字符串)
最基础的类型，常用于：
*   **缓存**：存储 JSON 对象。
*   **计数器**：`INCR`, `DECR`。
*   **分布式锁**：`SETNX`。

**常用命令：**
```bash
SET user:1 '{"name":"Jack"}' EX 3600 # 设置值及过期时间
GET user:1
INCR total_views # 自增
SETNX lock_key "unique_id" # 不存在则设置（分布式锁核心）
```

**Java 代码示例 (Spring Boot):**
```java
// 使用 StringRedisTemplate
stringRedisTemplate.opsForValue().set("user:1", jsonString, 1, TimeUnit.HOURS);
Long views = stringRedisTemplate.opsForValue().increment("total_views");
```

## 2. Hash (哈希)
类似于 Java 的 `HashMap`，适合存储对象：
*   **用户信息维护**：`HSET user:1 name "Tom" age 20`。

**常用命令：**
```bash
HSET user:100 name "Tom" age 25
HGET user:100 name
HGETALL user:100 # 获取所有字段
HINCRBY user:100 age 1 # 年龄加1
```

## 3. List (列表)
双向链表，支持从两端插入/弹出：
*   **消息队列**：`LPUSH` + `BRPOP`。
*   **最新消息展示**。

**常用命令：**
```bash
LPUSH news_list 101 102 103 # 从左侧插入
RPOP news_list # 从右侧弹出
LRANGE news_list 0 10 # 获取前11个元素
```

## 4. Set (集合)
无序去重集合：
*   **去重功能**。
*   **求交集/并集/差集**：如共同关注、好友推荐。

**常用命令：**
```bash
SADD tags:1 "java" "redis" "mysql"
SISMEMBER tags:1 "java" # 判断是否存在
SINTER tags:1 tags:2 # 交集
```

## 5. ZSet (有序集合)
每个元素关联一个 Score，按 Score 排序：
*   **排行榜**。
*   **延时队列**：Score 设为过期时间戳。

**常用命令：**
```bash
ZADD ranking 95 "user_A" 88 "user_B" 100 "user_C"
ZREVRANGE ranking 0 2 WITHSCORES # 获取前三名
ZSCORE ranking "user_A" # 获取分数
```

## 6. 特殊类型
*   **Bitmaps**：布隆过滤器、打卡统计。
*   **HyperLogLog**：基数统计（UV 统计）。
*   **GEO**：地理位置查询。
