# 5. Spring Boot 集成 Redis

在 Java 开发中，Spring Data Redis 是集成 Redis 的事实标准。

## 1. 引入依赖
在 `pom.xml` 中添加 starter 依赖：
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
<!-- 连接池依赖 -->
<dependency>
    <groupId>org.apache.commons</groupId>
    <artifactId>commons-pool2</artifactId>
</dependency>
```

## 2. 基础配置
在 `application.yml` 中配置连接信息：
```yaml
spring:
  redis:
    host: localhost
    port: 6379
    password: yourpassword
    lettuce:
      pool:
        max-active: 8 # 最大连接数
        max-idle: 8   # 最大空闲连接
        min-idle: 0   # 最小空闲连接
```

## 3. 自定义配置类 (解决序列化问题)
默认的 `RedisTemplate` 使用 JDK 序列化（会产生乱码），通常我们需要配置为 JSON 序列化：
```java
@Configuration
public class RedisConfig {

    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(factory);

        // 设置 Key 的序列化方式为 String
        template.setKeySerializer(new StringRedisSerializer());
        // 设置 Value 的序列化方式为 JSON
        GenericJackson2JsonRedisSerializer jsonSerializer = new GenericJackson2JsonRedisSerializer();
        template.setValueSerializer(jsonSerializer);

        template.setHashKeySerializer(new StringRedisSerializer());
        template.setHashValueSerializer(jsonSerializer);

        template.afterPropertiesSet();
        return template;
    }
}
```

## 4. RedisTemplate 手动操作
除了使用注解，更多场景下我们需要通过 `RedisTemplate` 手动控制逻辑。

```java
@Service
public class RedisService {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    public void example() {
        // 1. 操作字符串
        redisTemplate.opsForValue().set("key", "value", 60, TimeUnit.SECONDS);
        Object val = redisTemplate.opsForValue().get("key");

        // 2. 操作哈希
        redisTemplate.opsForHash().put("user:100", "name", "Jack");
        Object name = redisTemplate.opsForHash().get("user:100", "name");

        // 3. 操作列表 (模拟队列)
        redisTemplate.opsForList().leftPush("queue", "task1");
        Object task = redisTemplate.opsForList().rightPop("queue");

        // 4. 判断 key 是否存在
        Boolean hasKey = redisTemplate.hasKey("key");

        // 5. 删除 key
        redisTemplate.delete("key");
    }
}
```

## 5. 常用注解使用
使用 Spring Cache 注解前，通常需要注意以下两点：
1.  **无需额外依赖**：Spring Boot Starter Data Redis 已经包含了所有的核心支持。
2.  **必须开启缓存**：在主类（或配置类）上添加 **`@EnableCaching`** 注解。

*   **@Cacheable**：触发缓存逻辑。
*   **@CacheEvict**：清空缓存。
*   **@CachePut**：更新缓存。

### 完整 CRUD 流程示例
```java
@Service
@CacheConfig(cacheNames = "userCache") // 统一配置当前类的缓存区间名称
public class UserService {

    @Autowired
    private UserRepository userRepository;

    // 1. 查询 (C)：先从 Redis 找 userCache::id，没有则执行方法并存入 Redis
    @Cacheable(key = "#id")
    public User getUserById(Long id) {
        return userRepository.findById(id).orElse(null);
    }

    // 2. 更新 (U)：执行方法更新数据库，并同步更新 Redis 中的数据
    @CachePut(key = "#user.id")
    public User updateUser(User user) {
        userRepository.save(user);
        return user;
    }

    // 3. 删除 (D)：执行方法删除数据库数据，并同步从 Redis 中移除该 Key
    @CacheEvict(key = "#id")
    public void deleteUser(Long id) {
        userRepository.deleteById(id);
    }
    
    // 4. 清空：移除 userCache 区间下的所有 Key
    @CacheEvict(allEntries = true)
    public void clearAllUserCache() {
        // 用于管理员后台手动强制刷新缓存
    }
}
```
