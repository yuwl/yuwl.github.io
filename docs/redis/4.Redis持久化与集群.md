# 4. Redis 持久化与集群

## 1. 持久化机制
*   **RDB (Redis Database)**：快照方式，适合全量备份，恢复快。
*   **AOF (Append Only File)**：日志方式，数据更安全。

**运维命令：**
```bash
SAVE # 阻塞式持久化
BGSAVE # 后台异步持久化
BGREWRITEAOF # 重写 AOF 文件以减小体积
```

## 2. 主从架构
*   解决读写分离，从节点通过 `replicaof <masterip> <masterport>` 指定主节点。

**查看集群状态：**
```bash
INFO replication
```

## 3. 哨兵模式 (Sentinel)
*   监控主节点状态，自动故障转移。

**哨兵配置关键点 (`sentinel.conf`):**
```conf
sentinel monitor mymaster 127.0.0.1 6379 2
```

## 4. 集群模式 (Cluster)
*   **虚拟槽 (Hash Slot)**：共有 16384 个槽位。

**集群相关命令：**
```bash
redis-cli --cluster create 192.168.1.1:6379 192.168.1.2:6379 ... --cluster-replicas 1
CLUSTER INFO # 查看集群信息
CLUSTER NODES # 查看节点槽位分配
```
