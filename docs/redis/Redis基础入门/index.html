1. Redis 基础入门

Redis (Remote Dictionary Server) 是一款开源的、高性能的 KEY-VALUE 内存数据库。

1. 为什么选择 Redis？​

  • 内存存储：读写性能极高（10W+ QPS）。
  • 丰富的数据类型：支持 String, Hash, List, Set, ZSet 等。
  • 持久化：支持 RDB 和 AOF，保证数据不丢失。
  • 原子性：所有操作都是原子性的。
  • 高可用/集群：Sentinal（哨兵）和 Cluster（集群）模式。

2. 核心特性​

  • 单线程模型：Redis 6.0 之前核心处理逻辑是单线程，避免了线程切换和锁竞争。
  • 多路复用：基于 epoll 实现非阻塞 I/O。

3. 安装与运行​

3.1 Linux 本地安装 (以 Ubuntu/CentOS 为例)​

在 Linux 上通常通过源码编译安装以获得最佳性能：

# 下载并解压
wget https://download.redis.io/redis-stable.tar.gz
tar -xzvf redis-stable.tar.gz
cd redis-stable

# 编译
make
# 安装到指定目录
sudo make install

启动服务：redis-server

3.2 Windows 本地安装​

Redis 官方不正式支持 Windows，但有以下几种方案：

  1. 中文网直接下载 (常用)：通过 Redis 中文网 下载 Windows 版本的安装包或绿色版，这是国内非常方便的获取方式。
  2. WSL2 (推荐)：在 Windows 子系统 Linux 中按照上述 Linux 步骤安装，性能最接近生产环境。

Windows 启动方式：

  • 临时启动：进入 Redis 解压目录，打开终端执行： 
    redis-server.exe redis.windows.conf
  • 服务启动（推荐）：将 Redis 安装为 Windows 服务，实现开机自启： 
    # 安装服务
    redis-server --service-install redis.windows.conf --loglevel verbose
    # 启动服务
    redis-server --service-start
    # 停止服务
    redis-server --service-stop

3.3 Docker 快速启动 (推荐测试使用)​

通常使用 Docker 快速启动：

docker run -d --name redis -p 6379:6379 redis:latest

4. 客户端连接​

使用 redis-cli：

# 连接本地默认端口
redis-cli

# 连接远程服务器
redis-cli -h 127.0.0.1 -p 6379 -a password

# 测试连通性
ping # 返回 PONG 表示成功

5. 核心配置优化 (redis.conf)​

在生产环境中，通常需要调整以下配置：

  • bind 0.0.0.0：允许远程连接（注意安全）。
  • requirepass yourpassword：设置访问密码。
  • maxmemory 2gb：设置最大内存上限。
  • maxmemory-policy allkeys-lru：内存淘汰策略（LRU）。
