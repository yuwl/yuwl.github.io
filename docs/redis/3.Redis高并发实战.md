# 3. Redis 高并发实战

在 Java 后端开发中，Redis 是解决高并发问题的利器。

## 1. 缓存三兄弟
*   **缓存穿透**：请求根本不存在的数据。
    *   *方案*：缓存空对象、使用布隆过滤器。
*   **缓存击穿**：热点 Key 过期瞬间，大并发打到 DB。
    *   *方案*：热点数据永不过期、加互斥锁（SETNX）。
*   **缓存雪崩**：大量 Key 同时过期。
    *   *方案*：过期时间加随机值、多级缓存。

## 2. 分布式锁
使用 `SET key value NX PX 30000` 实现简单的分布式锁。建议在生产环境使用 **Redisson**，它解决了锁续期（看门狗机制）和可重入性问题。

### Redisson 完整使用步骤

#### 1. 引入依赖
在 `pom.xml` 中引入 Redisson 的 Spring Boot Starter：
```xml
<dependency>
    <groupId>org.redisson</groupId>
    <artifactId>redisson-spring-boot-starter</artifactId>
    <version>3.17.4</version>
</dependency>
```

#### 2. 配置 (application.yml)
如果已经配置了 `spring.redis`，Redisson Starter 会自动复用配置。若需特殊定制：
```yaml
spring:
  redis:
    host: localhost
    port: 6379
```

#### 3. 代码示例
```java
@Autowired
private RedissonClient redissonClient;

public void handleOrder() {
    RLock lock = redissonClient.getLock("order_lock");
    try {
        // 尝试加锁，最多等待10秒
        // 注意：如果不填租约时间(leaseTime)，Redisson 会启用“看门狗”进行每10秒一次的续期
        // 如果填了(如30)，到时间后锁会自动释放，哪怕业务没执行完。此时建议：
        // 1. 不设置 leaseTime（推荐，依靠看门狗）
        // 2. 设置足够长的 leaseTime
        if (lock.tryLock(10, 30, TimeUnit.SECONDS)) {
            // 执行业务逻辑
        }
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    } finally {
        // 只有加锁成功的线程才尝试解锁
        if (lock.isHeldByCurrentThread()) {
            lock.unlock();
        }
    }
}
```

## 3. 读写一致性
*   **先删缓存，再更新 DB**：可能导致脏数据。
*   **先更新 DB，再删缓存**：业内主流做法（Cache Aside Pattern）。
*   **延迟双删**：极端情况下保证一致性。

## 4. 秒杀限流 (Lua 脚本)
利用 Lua 脚本保证“查库存+减库存”的原子性，防止超卖。

#### 1. 定义 Lua 脚本
通常将脚本放在 `resources` 目录下，或者直接在 Java 代码中定义。

```lua
-- seckill.lua
local stock_key = KEYS[1]
local buy_num = tonumber(ARGV[1])
local current_stock = tonumber(redis.call('get', stock_key) or "0")

if current_stock >= buy_num then
    redis.call('decrby', stock_key, buy_num)
    return 1 -- 成功
else
    return 0 -- 库存不足
end
```

#### 2. Java 实现代码
```java
@Service
public class SeckillService {

    @Autowired
    private StringRedisTemplate stringRedisTemplate;

    // 提前加载脚本以提高性能
    private static final DefaultRedisScript<Long> SECKILL_SCRIPT;

    static {
        SECKILL_SCRIPT = new DefaultRedisScript<>();
        // 脚本位置：src/main/resources/lua/seckill.lua
        SECKILL_SCRIPT.setLocation(new ClassPathResource("lua/seckill.lua"));
        SECKILL_SCRIPT.setResultType(Long.class);
    }

    public boolean doSeckill(String itemId, int num) {
        String key = "stock:" + itemId;
        // 执行脚本
        // 参数1：脚本对象, 参数2：KEYS列表, 参数3：ARGV可变参数
        Long result = stringRedisTemplate.execute(
            SECKILL_SCRIPT, 
            Collections.singletonList(key), 
            String.valueOf(num)
        );
        
        return result != null && result == 1;
    }
}
```
