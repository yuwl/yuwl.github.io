# 2. Elasticsearch 核心概念与实战

深入理解 Elasticsearch 的核心概念是掌握其搜索与分析能力的关键。

## 一、 核心术语

### 1. 索引 (Index)
索引是具有相似特征的文档集合。类比于关系型数据库中的 **“数据库”**。

### 2. 文档 (Document)
文档是可以被索引的基础信息单位，以 JSON 格式表示。类比于关系型数据库中的 **“行”**。

### 3. 字段 (Field)
文档由多个字段组成。类比于关系型数据库中的 **“列”**。

### 4. 映射 (Mapping)
映射是定义文档及其包含的字段如何被存储和索引的过程。

### 5. 分片与副本 (Shards & Replicas)
- **分片 (Shard)**：将索引划分为多份的能力，允许水平分割和扩展容量。
- **副本 (Replica)**：分片的一个或多个拷贝，用于容错和提高查询效率。

---

## 二、 映射与数据类型 (Mapping)

### 1. 常用字段数据类型

- **字符串**:
  - `text`: 用于全文检索。会被分词，支持模糊查询。
  - `keyword`: 用于精确匹配。不分词，常用于过滤、排序、聚合。
- **数值**: `long`, `integer`, `short`, `double`, `float` 等。
- **其他**: `boolean` (布尔), `date` (日期), `geo_point` (地理位置)。
- **复杂类型**: `object` (嵌套对象), `nested` (可独立索引的嵌套数组)。

### 2. Mapping 定义示例

```json
{
  "mappings": {
    "properties": {
      "title": { "type": "text" },        // 全文搜索
      "author": { "type": "keyword" },    // 精确匹配
      "price": { "type": "double" },      // 数值
      "publish_date": { "type": "date" }, // 日期
      "tags": { "type": "keyword" }       // 关键词数组
    }
  }
}
```

## 三、 命令行实战 (REST API)

以下操作均可在 Kibana 的 **Dev Tools** 中直接运行。

### 1. 索引操作 (CRUD)

```bash
# 创建索引并指定 Mapping
PUT /my_index
{
  "mappings": {
    "properties": {
      "name": { "type": "text" },
      "type": { "type": "keyword" }
    }
  }
}

# 查看 Mapping
GET /my_index/_mapping

# 修改 Mapping (仅允许新增字段)
PUT /my_index/_mapping
{
  "properties": {
    "address": { "type": "text" }
  }
}

# 删除索引
DELETE /my_index
```

### 2. 文档操作 (CRUD)

```bash
# 新增文档 (指定 ID)
PUT /my_index/_doc/1
{
  "name": "Elasticsearch",
  "type": "Search Engine"
}

# 查询文档
GET /my_index/_doc/1

# 更新文档 (增量更新)
POST /my_index/_update/1
{
  "doc": { "tags": ["fast"] }
}

# 删除文档
DELETE /my_index/_doc/1
```

## 四、 搜索与聚合

### 1. 常用查询 (Query DSL)

- **全文搜索 (Match)**
  ```bash
  GET /my_index/_search
  { "query": { "match": { "name": "Elasticsearch" } } }
  ```
- **布尔组合 (Bool)**
  ```bash
  GET /my_index/_search
  {
    "query": {
      "bool": {
        "must": [{ "match": { "name": "Elasticsearch" } }],
        "filter": [{ "range": { "price": { "gte": 10 } } }]
      }
    }
  }
  ```
- **精确匹配 (Term)**: 用于 `keyword` 字段。
- **短语匹配 (Match Phrase)**: 匹配完整短语。

### 2. 聚合分析 (Aggregations)

- **分桶聚合 (Terms)**: 类似 SQL `GROUP BY`。
  ```bash
  GET /my_index/_search
  {
    "aggs": {
      "group_by_type": { "terms": { "field": "type" } }
    },
    "size": 0
  }
  ```
- **指标聚合 (Metrics)**: 类似 `AVG`, `SUM`, `MAX`。
  ```bash
  GET /my_index/_search
  {
    "aggs": {
      "avg_price": { "avg": { "field": "price" } }
    },
    "size": 0
  }
  ```
