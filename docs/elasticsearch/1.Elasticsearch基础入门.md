# 1. Elasticsearch 基础入门

Elasticsearch 是一个分布式、RESTful 风格的搜索和数据分析引擎。

## 什么是 Elasticsearch？

Elasticsearch 是一个基于 Lucene 的搜索服务器。它提供了一个分布式多用户能力的全文搜索引擎，基于 RESTful web 接口。Elasticsearch 是用 Java 开发的，并作为 Apache 许可条款下的开放源码发布，是当前流行的企业级搜索引擎。

## 核心特性

- **分布式**：横向扩展非常方便。
- **全文检索**：强大的搜索能力。
- **近实时（NRT）**：从索引文档到可搜索只有约 1 秒的延迟。
- **RESTful API**：通过简单的 HTTP 请求即可与之交互。

## 安装与运行

### 1. 使用 Docker 安装 (推荐)

这是最快的方式，可以同时启动 Elasticsearch 和 Kibana。

使用 `docker-compose.yml`:

```yaml
version: '7.5'
services:
  elasticsearch:
    image: docker.elastic.co/elasticsearch/elasticsearch:7.17.0
    container_name: elasticsearch
    environment:
      - discovery.type=single-node
      - "ES_JAVA_OPTS=-Xms512m -Xmx512m"
    ports:
      - "9200:9200"
      - "9300:9300"
  kibana:
    image: docker.elastic.co/kibana/kibana:7.17.0
    container_name: kibana
    ports:
      - "5601:5601"
    environment:
      - ELASTICSEARCH_URL=http://elasticsearch:9200
    depends_on:
      - elasticsearch
```

运行 `docker-compose up -d` 即可。

### 2. 本地下载安装

1.  **Elasticsearch**: 
    - 下载对应操作系统的压缩包（zip/tar.gz）。
    - 解压后进入 `bin` 目录，执行 `./elasticsearch` (Linux/Mac) 或 `elasticsearch.bat` (Windows)。
2.  **Kibana**:
    - 下载版本需与 ES 保持一致。
    - 修改 `config/kibana.yml` 中的 `elasticsearch.hosts`。
    - 执行 `bin/kibana`。

## 调试工具 Kibana

Kibana 是一个为 Elasticsearch 设计的开源分析和可视化平台。

- **访问地址**: 默认 `http://localhost:5601`
- **Dev Tools**: 在 Kibana 左侧菜单找到 "Dev Tools"，这是学习和调试 DSL 语句最方便的地方。
  - 例如输入 `GET /` 并运行，可以查看 ES 节点状态。
