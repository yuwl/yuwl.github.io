# 3. Spring Boot 集成 Elasticsearch

在 Spring Boot 项目中，使用 **Spring Data Elasticsearch** 是最主流的选择，它通过 Repository 模式极大地简化了数据的 CRUD 操作。

## 一、 核心依赖

在 `pom.xml` 中引入起步依赖。请确保版本与你的 Elasticsearch 服务版本匹配。

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-elasticsearch</artifactId>
</dependency>
```

---

## 二、 基础配置

在 `application.yml` 或 `application.properties` 中配置连接地址：

```yaml
spring:
  elasticsearch:
    uris: http://localhost:9200
    # 如果有用户名密码，取消下方注释
    # username: elastic
    # password: your_password
```

---

## 三、 实体类与映射

使用 `@Document` 注解声明索引信息，并通过注解定义字段类型。

```java
import org.springframework.data.annotation.Id;
import org.springframework.data.elasticsearch.annotations.Document;
import org.springframework.data.elasticsearch.annotations.Field;
import org.springframework.data.elasticsearch.annotations.FieldType;

@Document(indexName = "products")
public class Product {
    
    @Id
    private String id;

    @Field(type = FieldType.Text, analyzer = "ik_max_word")
    private String name;

    @Field(type = FieldType.Keyword)
    private String category;

    @Field(type = FieldType.Double)
    private Double price;

    @Field(type = FieldType.Integer)
    private Integer stock;

    // Getters and Setters ...
}
```

## 四、 持久层 (Repository)

继承 `ElasticsearchRepository` 即可获得基础的 CRUD 和分页查询能力。

```java
import org.springframework.data.elasticsearch.repository.ElasticsearchRepository;
import java.util.List;

public interface ProductRepository extends ElasticsearchRepository<Product, String> {
    
    // 支持按方法名解析查询
    List<Product> findByNameContaining(String name);
    
    List<Product> findByPriceBetween(Double min, Double max);
}
```

## 五、 进阶：使用 ElasticsearchRestTemplate

如果 Repository 无法满足复杂的搜索需求（如复杂的聚合、多条件组合），可以使用 `ElasticsearchRestTemplate`。

```java
@Service
public class ProductService {

    @Autowired
    private ElasticsearchRestTemplate elasticsearchRestTemplate;

    public void complexSearch() {
        NativeSearchQuery searchQuery = new NativeSearchQueryBuilder()
                .withQuery(QueryBuilders.matchQuery("name", "手机"))
                .withFilter(QueryBuilders.rangeQuery("price").gte(1000))
                .withPageable(PageRequest.of(0, 10))
                .build();

        SearchHits<Product> hits = elasticsearchRestTemplate.search(searchQuery, Product.class);
        // 处理查询结果...
    }
}
```

## 六、 常见问题

1.  **版本匹配**：Spring Data Elasticsearch 的版本对 ES 服务器版本非常敏感，建议查看 [官方兼容性矩阵](https://docs.spring.io/spring-data/elasticsearch/docs/current/reference/html/#preface.versions)。
2.  **自动创建索引与 Mapping**：
    *   **默认行为**：Spring Data 默认会在首次操作实体类时，根据注解自动创建索引和 Mapping（`@Document(createIndex = true)`）。
    *   **生产建议**：推荐**手动提前创建**。原因包括：可以精确配置分片/副本数、预设分词器（如 IK）、避免自动推断类型错误（Mapping 一旦建立字段类型不可修改）。
    *   **手动控制**：若需完全手动，可设置 `@Document(indexName = "products", createIndex = false)`。
